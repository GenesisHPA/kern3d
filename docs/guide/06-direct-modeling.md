# Прямое моделирование

Вкладка **«Прямое моделирование»** — это работа с готовыми формами «как с пластилином»: нарисовали линию или параллелепипед, скруглили ребро, вычли одно тело из другого — и получили новую форму. Здесь нет дерева операций, как на вкладке «Тело»: у каждого объекта есть только его текущая форма и несколько размеров в панели «Свойства». На этой странице — все кнопки вкладки, кроме перемещения, поворота, массивов, измерений и аннотаций: они описаны на странице [Перемещение, измерения, анализ и аннотации](07-modify-and-measure.md).

## 1. Прямое моделирование и «Тело»: в чём разница

| | Вкладка «Тело» ([страница 05](05-body-parametric.md)) | Вкладка «Прямое моделирование» |
|---|---|---|
| Что хранится | Список операций: эскиз → выдавливание → отверстие → скругление… Форма каждый раз пересчитывается из этого списка | Только готовая форма. Как она получилась, программа не помнит |
| Правка задним числом | Поменяли размер в эскизе — пересчиталось всё тело | Нельзя. Можно только поменять параметры самого простого объекта (длину параллелепипеда, радиус окружности) в «Свойствах», пока его не изменили другой командой |
| Шкала истории внизу | Заполняется | Не заполняется (действия видны только в отмене Ctrl+Z) |
| Когда удобно | Детали, которые придётся переделывать: корпуса, кронштейны, всё «по размерам» | Быстрые черновики, вспомогательная геометрия, правка импортированных STEP/STL-тел, кривые и поверхности (лофт, сдвиг, спираль), которых нет на вкладке «Тело» |

Что важно знать:

- Объект прямого моделирования после первой же изменяющей команды (скругление, оболочка, булева операция и т. п.) становится просто **фигурой** — в «Свойствах» у него больше нет длины и ширины, только материал и тип фигуры.
- Команды вкладки «Прямое моделирование» можно применить и к телу с вкладки «Тело» (например, скруглить его ребро). Но тогда тело **заменяется обычной фигурой и теряет список операций**. Если это сделано по ошибке — Ctrl+Z. Чтобы скруглить параметрическое тело и сохранить историю, используйте **«Тело» → «Изменить» → «Скругление»**.
- Обе вкладки работают в одном документе; объекты обоих видов (и тела, и кривые, и поверхности) лежат в браузере слева в разделе «Тела» (в режиме «По типам»).

## 2. Где кнопки

Переключатель слева в строке команд должен стоять на **«Конструирование»**, затем вкладка **«Прямое моделирование»** (между «Тело» и «Утилиты»).

Группы вкладки слева направо:

| Группа | Что в ней | Где описано |
|---|---|---|
| **Рисование** | Линии, дуги, окружности, примитивы, выдавливание, вращение, сдвиг, лофт, а в конце списка — точка, многоугольник, Безье, спираль, труба, текст | [разделы 4](#4-рисование-линии-кривые-плоские-фигуры) и [5](#5-рисование-тела-и-поверхности) |
| **Изменить** | Переместить, повернуть, отразить, массив, «Переместить/Копировать», «Выровнять», «Удалить узел» — **на [странице 07](07-modify-and-measure.md)**; обрезка, удлинение, оболочка, разделение, прошивка, упрощение, скругление, фаска, разбиение, удаление фигур и функций, внешний вид, шаблоны граней — здесь | [раздел 7](#7-изменить-скругление-фаска-оболочка-обрезка-и-другие) |
| **Конвертер** | В контур, в составной объект, в грань, в оболочку, в тело | [раздел 8](#8-конвертер-в-контур-грань-оболочку-тело) |
| **Булевый** | Пересечение, вычитание, объединение | [раздел 9](#9-булевы-операции-объединение-вычитание-пересечение) |
| **Рабочая плоскость** | Динамическая рабочая плоскость, задать рабочую плоскость и др. | [раздел 10](#10-рабочая-плоскость) |
| **Инструменты** | Проекция, группа, сечение, смещение, копировать фигуру, исправить и проверить фигуру | [раздел 11](#11-инструменты-проекция-группа-сечение-смещение-копия-проверка) |
| **Измерение**, **Анализ**, **Аннотация**, **Акт** | Длина, угол, измерить выбранное; анализ сечения, пересечения тел, массовые свойства; размеры и текст; выровнять камеру | [страница 07](07-modify-and-measure.md) |
| **Импорт/Экспорт** | Импорт и экспорт файлов | [раздел 12](#12-импортэкспорт-и-остальное) |
| **Остальное** | ИИ-помощник | [раздел 12](#12-импортэкспорт-и-остальное) |

**Как устроена группа.** Над названием группы видны значки только самых частых команд:

- «Рисование»: Линия, Прямоугольник, Дуга, Параллелепипед, Выдавливание;
- «Изменить»: только Переместить;
- «Конвертер»: В контур, В составной объект;
- «Инструменты»: Проекция, Группа;
- «Булевый» — значков нет, только список.

Все остальные команды — в **списке группы**: щёлкните по названию группы со стрелкой (например, **«Рисование ▾»**). В списке видны все команды по порядку, справа — горячая клавиша. Команды, которые на старой ленте были «спрятаны» (точка, многоугольник, Безье, спираль, труба, текст; разбить, внешний вид, шаблоны; исправить и проверить фигуру), стоят в конце списка.

Значки можно переставлять: перетащите значок мышью, перетащите строку из списка на панель, или в списке нажмите булавку **«Показать на панели»** / **«Убрать с панели»**. **«Сбросить расположение значков»** в списке возвращает всё как было. Расположение запоминается для каждой группы.

Любую команду можно найти и поиском команд по названию (клавиша **S**, см. [страницу 01](01-start-and-interface.md)).

## 3. Как работает любая команда: щелчки, числа, панель

Почти все команды вкладки устроены одинаково.

1. **Нажмите кнопку.** Справа на окне модели открывается **панель команды**: сверху значок и название команды, ниже — её параметры (галочки, поля, списки), внизу кнопки. Панель можно перетащить за заголовок; следующая панель откроется там же.
2. **Читайте подсказку в строке состояния** внизу — она говорит, что сейчас нужно указать: «выберите точку начала, ESC для отмены», «Пожалуйста выберите фигуру» и т. д.
3. **Указывайте точки щелчком.** Работают привязки к концам, серединам, центрам, пересечениям (кнопка «Привязка ▲» в строке состояния) и отслеживание. Точки ложатся на **рабочую плоскость** (по умолчанию XY); если включена динамическая рабочая плоскость — на грань под курсором. Подробно — [страница 03](03-view-and-selection.md).
4. **Или вводите числа.** Начните набирать цифру (или «-», или «#») — появится поле ввода; **Enter** применяет число.

   | Что набрать | Что получится |
   |---|---|
   | `25` | Точка на расстоянии 25 мм от предыдущей **в сторону курсора** (для радиуса — радиус 25, для высоты — высота 25) |
   | `40,30` | Смещение от предыдущей точки на 40 по X и 30 по Y рабочей плоскости. Знак берётся по тому, с какой стороны стоит курсор |
   | `40,30,10` | Смещение по X, Y и Z |
   | `#10,20,0` | Точка с абсолютными координатами X=10, Y=20, Z=0 (нужны ровно три числа) |
   | `45` на шаге угла | Угол 45° |

   Числа разделяются **запятой**, дробная часть — **точкой** (`12.5`). Ошибки ввода: «Вводите номера, разделенные запятой ','», «Не заполнена котрольная точка, нужно только 3 номера» (первую точку можно задать только тремя числами или щелчком), «Достигнут предел вводимых номеров» (на этом шаге столько чисел нельзя).
5. **Выбор объектов.** Где нужно выбрать несколько объектов, щёлкайте по ним по очереди или обведите рамкой; в панели видно **«Выбрано N»**. Закончить выбор — **Enter** (или пробел) или **✓ ОК** в панели. **Tab** перебирает объекты под курсором, если они перекрываются. Повторный щелчок снимает выбор.
6. **Отмена.** **Esc** или **✗ Отмена** в панели прерывают команду; уже созданное остаётся. Любое завершённое действие отменяется **Ctrl+Z**.
7. **Параметры запоминаются.** Значения в панели (радиус скругления, толщина оболочки…) сохраняются до следующего запуска той же команды, пока открыта программа.

Если объект уже выделен до нажатия кнопки, многие команды (разбить на части, прошить, исправить, проверить, группа, конвертер) берут его сразу и не спрашивают.

## 4. «Рисование»: линии, кривые, плоские фигуры

Все кривые и плоские фигуры строятся в рабочей плоскости (или в плоскости грани, если включена динамическая рабочая плоскость). Плоские замкнутые фигуры (прямоугольник, окружность, эллипс, многоугольники) по умолчанию создаются **залитыми гранями** — их сразу можно выдавливать. За это отвечает галочка **«Вперед»** в панели команды и в «Свойствах» (так в программе подписан параметр «Грань»): включена — грань, выключена — только контур.

### 4.1. Линия (отрезок)

**«Прямое моделирование» → «Рисование» → «Линия»**, клавиша **L**.

1. Щёлкните первую точку («выберите точку начала, ESC для отмены»).
2. Щёлкните вторую или введите длину / смещение («выберите следующую точку, ESC для отмены»).
3. Команда сразу предлагает следующий отрезок. Галочка **«Соединение»** (включена) — новый отрезок начинается в конце предыдущего, получается ломаная; выключена — каждый отрезок начинается с нового щелчка.
4. Закончить — **Esc**.

Каждый отрезок — отдельный объект «Линия» со свойствами **«Начало»** и **«Конец»**. Чтобы собрать ломаную в один контур, используйте [«В контур»](#8-конвертер-в-контур-грань-оболочку-тело).

### 4.2. Прямоугольник

**«Рисование» → «Прямоугольник»** (первый в выпадающей кнопке вместе с окружностью, эллипсом и правильным многоугольником), клавиша **R**.

1. Первый угол.
2. Противоположный угол — щелчком или числами `длина,ширина` (например `40,30`). Возле курсора показываются текущие размеры.

Параметры панели: **«Вперед»** (грань / контур), **«Центр прямоугольника»** — первая точка становится центром, а не углом.

Свойства: **«Длина»**, **«Ширина»**, «Вперед».

### 4.3. Окружность

**«Рисование» → «Окружность»**, клавиша **C**.

1. Центр («выберите центр, ESC для отмены»).
2. Точка на окружности или число — **радиус** («введите радиус, ESC для отмены»).

Свойства: **«Центр»**, **«Радиус»**, «Вперед».

### 4.4. Эллипс

**«Рисование» → «Эллипс»**.

1. Центр.
2. Конец большой полуоси (задаёт её длину и направление).
3. Конец малой полуоси (расстояние поперёк). Малая полуось не может быть больше большой — программа ограничит её.

Свойства: **«Центр»**, **«максимальный Радиус»**, **«минимальный Радиус»**, «Вперед».

### 4.5. Правильный многоугольник (шестигранник)

**«Рисование» → «Правильный многоугольник»**.

1. Центр.
2. Точка — вершина многоугольника (радиус описанной окружности и поворот).

Параметр **«Число сторон»** — от 3, по умолчанию 6 (шестигранник под гайку). Свойства: «Центр», «Радиус», «Число сторон», «Вперед».

### 4.6. Дуга (центр, радиус, угол)

**«Рисование» → «Дуга»** (выпадающая кнопка с четырьмя способами построения дуги).

1. Центр.
2. Начало дуги — задаёт радиус.
3. Конец дуги — задаёт угол (можно ввести число в градусах).

Свойства: **«Центр»**, **«Начать»** (точка начала), **«Угол»**.

### 4.7. Дуга в 2 точки

**«Рисование» → «Дуга в 2 точки»**: начало, конец («выберите точку завершения, ESC для отмены»), затем высота дуги — насколько середина дуги отходит от хорды («введите высоту дуги, ESC для отмены»).

### 4.8. Дуга в 3 точки

**«Рисование» → «Дуга в 3 точки»**: начало, точка на дуге («выберите точку на дуге, ESC для отмены»), конец. Три точки не должны лежать на одной прямой.

### 4.9. Дуга TTR (касательная к двум, по радиусу)

**«Рисование» → «Дуга TTR»** — дуга заданного радиуса, касающаяся двух линий или дуг (как сопряжение).

1. Выберите две кривые — отрезки, окружности или дуги («Пожалуйста выберите конечности»). Щёлкайте ближе к тем концам, у которых нужно сопряжение: от этого зависит, какое из возможных решений будет построено. После второго щелчка выбор заканчивается сам.
2. Задайте радиус: курсором (радиус растёт от точки посередине между щелчками) или числом.

Обе кривые должны лежать в одной плоскости. Если при каком-то радиусе касательной дуги нет, превью пропадает — увеличьте или уменьшите радиус.

### 4.10. Точка

**«Рисование ▾» → «Точка»** (в конце списка). Один щелчок или координаты `#x,y,z`. Свойство: **«Положение»**. Пригодится как опорная точка для привязки.

### 4.11. Многоугольник (ломаная, полилиния)

**«Рисование ▾» → «Многоугольник»**.

1. Щёлкайте вершины одну за другой.
2. Чтобы **замкнуть**, щёлкните по первой точке (возле неё появляется подсказка «Закрыть»).
3. Чтобы закончить **незамкнутую** ломаную — **Enter**, пробел или **✓ ОК** в панели. **Esc** — отмена без создания.

Получается один объект «Полигон» со свойством **«Точки»**; галочка «Вперед» делает замкнутый многоугольник гранью.

### 4.12. Кривая Безье

**«Рисование ▾» → «Кривая Безье»**. Щёлкайте управляющие точки (между ними рисуется пунктирная ломаная); кривая проходит через первую и последнюю точку и тянется к промежуточным. Закончить — Esc или Enter (нужно хотя бы 2 точки), замкнуть — щелчок по первой точке. Получается фигура «Кривая Безье» (без редактируемых размеров).

### 4.13. Спираль (helix)

**«Рисование ▾» → «Спираль»** — винтовая линия, например путь для пружины или резьбы.

1. Центр основания.
2. Радиус.
3. Высота (вдоль нормали рабочей плоскости, вверх или вниз).

Параметр **«Шаг»** — расстояние между витками, по умолчанию 10 мм; число витков = высота / шаг. Свойства: «Центр», «Радиус», «Шаг», «Угол» (полный угол закрутки в градусах).

Ошибки (выводятся по-английски): «The pitch must be non-zero» — шаг 0; «Helix radius and length must be positive» — нулевой радиус или высота.

Пружину из спирали делают командой [«Сдвиг»](#58-сдвиг-sweep-протягивание-по-пути): профиль — окружность на конце спирали, путь — спираль.

### 4.14. Text (объёмный текст)

**«Рисование ▾» → «Text»** (кнопка подписана по-английски). Делает **объёмные буквы** — тело для гравировки, таблички, надписи на детали. (Для текстовой пометки-выноски есть [аннотация «Текст»](07-modify-and-measure.md).)

Параметры панели:

| Поле | Что значит |
|---|---|
| **Текст** | Строка текста, по умолчанию «Text» |
| **Высота** | Высота букв, мм (по умолчанию 10) |
| **Шрифт** | Щелчок открывает выбор шрифта: шрифты из каталога (скачиваются), шрифты этого компьютера (в Chrome/Edge), или файл .ttf/.otf/.woff. Подписи окна английские |
| **Place by** | Способ размещения: **Two Points** (по двум точкам) или **Following a Path** (вдоль кривой) |

По двум точкам:

1. Точка начала строки.
2. Направление строки («pick the direction the text runs in…» — подсказка английская). Текст сразу виден на месте.
3. Глубина букв: потяните курсор от плоскости текста или введите число.

Вдоль кривой: выберите кривую («Пожалуйста выберите путь»), затем глубину.

Свойства готового текста: «Положение», «Текст», «Высота», **«Depth»** (глубина), «Шрифт». Чтобы исправить текст, программе нужен тот же шрифт; если его нет — «This text's font is not at hand — pick it again to change the text»: выберите шрифт заново. Если шрифт не скачался — «Не удалось загрузить шрифт текста».

## 5. «Рисование»: тела и поверхности

### 5.1. Параллелепипед (куб, коробка)

**«Рисование» → «Параллелепипед»** (выпадающая кнопка с примитивами: параллелепипед, сфера, цилиндр, конус, пирамида), клавиша **B**.

1. Первый угол основания.
2. Противоположный угол основания — щелчком или `длина,ширина`.
3. Высота: курсором вверх/вниз или числом («выберите следующую точку, ESC для отмены»).

Свойства (объект называется «Коробка»): **«Положение»** (угол), **«Длина»**, **«Ширина»**, **«Высота»**.

<!-- SHOT 06-box-properties: в окне параллелепипед, он выделен, слева в «СВОЙСТВА» раскрыта группа «Коробка» с полями Положение, Длина, Ширина, Высота; как получить: runCommand "create.box", щёлкнуть три точки в окне (или ввести 0,0 → 40,30 → 20), затем щёлкнуть по коробке -->

### 5.2. Сфера (шар)

**«Рисование» → «Сфера»**: центр, затем радиус. Свойства: «Центр», «Радиус».

### 5.3. Цилиндр

**«Рисование» → «Цилиндр»**, клавиша **Y**: центр основания, радиус, высота. Свойства: «Центр», «Радиус», «Высота».

### 5.4. Конус

**«Рисование» → «Конус»**, клавиша **N**: центр основания, радиус основания, высота до вершины. Получается конус с острой вершиной (усечённый конус — на вкладке «Тело», «Конус» с верхним радиусом). Свойства: «Центр», «Радиус», «Высота».

### 5.5. Пирамида

**«Рисование» → «Пирамида»**: два угла прямоугольного основания, затем высота (от центра основания). Свойства: «Длина», «Ширина», «Высота».

### 5.6. Выдавливание (extrude, призма)

**«Рисование» → «Выдавливание»**, клавиша **P**.

1. Выберите профиль: грань, контур или ребро («Пожалуйста выберите фигуру»). Удобно — прямоугольник или окружность, нарисованные выше.
2. Тяните курсор или введите длину. Направление — по нормали профиля; отрицательное число — в другую сторону.

Что получится:

- замкнутый профиль (грань, замкнутый контур) — **тело**;
- незамкнутый (отрезок, дуга) — **поверхность** (стенка);
- неплоская грань — утолщается на заданное расстояние.

Параметр **«Delete Objects»** (подпись английская, включён) — после выдавливания исходный профиль удаляется. Выключите, если профиль ещё понадобится.

Свойства результата («Призма»): **«Длина»** — её можно менять потом.

### 5.7. Вращение (revolve)

**«Рисование ▾» → «Вращение»**.

1. Выберите профиль — ребро, контур или грань («Пожалуйста выберите секцию»).
2. Выберите **прямое** ребро — ось вращения («Пожалуйста выберите оси»). Ось — отдельный отрезок или прямое ребро другого объекта; профиль остаётся подсвеченным.

Параметры: **«Угол»** — по умолчанию 360° (полный оборот); **«Delete Objects»**.

Ошибки: «ошибка: Select a straight edge as the axis» — ось не прямая; «ошибка: The profile cannot be its own axis» — в качестве оси выбран сам профиль; «Вводите номера, разделенные запятой ','» — угол 0 или не число.

### 5.8. Сдвиг (sweep, протягивание по пути)

**«Рисование ▾» → «Сдвиг»** — протягивает профиль вдоль пути (трубки, поручни, пружины, жгуты).

1. Выберите профиль(и) — рёбра или контуры («Пожалуйста выберите секцию»), подтвердите **✓ ОК** или Enter.
2. Щёлкайте рёбра **пути** по одному («Пожалуйста выберите путь»): после каждого щелчка показывается превью. Путь — один контур или цепочка соединённых рёбер.
3. **✓ ОК** — построить.

Параметры: **«Скруглить углы»** — на изломах пути делать скруглённый переход (иначе острый угол); **«Delete Objects»**.

Ошибки: «Sweep requires a path» — путь не выбран; «A sweep path is one wire or a chain of edges» — выбран контур вместе с другими рёбрами или рёбра не соединены.

Профиль ставьте в начало пути перпендикулярно ему — иначе форма получится перекошенной.

### 5.9. Лофт (переход между сечениями)

**«Рисование ▾» → «Лофт»** (выпадающая кнопка «Лофт» / «Gordon Surface») — плавный переход между несколькими сечениями (например, от квадрата к кругу).

1. Щёлкайте сечения по порядку («Пожалуйста выберите секцию»): замкнутые контуры, рёбра, грани (берётся их внешний край) или вершину — только первой или последней (получится «острие»). После второго сечения видно полупрозрачное превью.
2. **✓ ОК** — построить.

Параметры:

| Поле | Что значит |
|---|---|
| **Твердый** | Включено — замкнутое тело; выключено — только боковая поверхность |
| **Управляемый** | Линейчатая поверхность: между сечениями прямые отрезки, без плавности |
| **Продолжительность** | Гладкость поверхности (c0, g1, c1, g2, c2, c3, cn) — доступна, когда «Управляемый» выключен |
| **Delete Objects** | Удалить сечения после построения |

Ошибки: «Loft requires at least 2 sections», «A loft section edge must be closed» (незамкнутое ребро), «Loft vertex sections must be first or last» (вершина в середине). Результат называется «loft».

### 5.10. Gordon Surface (поверхность по сетке кривых)

**«Рисование ▾» → «Gordon Surface»** (подпись английская) — поверхность по сетке: несколько профилей в одну сторону и несколько направляющих поперёк (как каркас крыла или корпуса лодки).

1. Выберите рёбра-**профили** (не меньше двух), Enter / ✓ ОК.
2. Выберите рёбра-**направляющие** (не меньше двух) — они должны пересекать профили; профили остаются подсвеченными. Enter / ✓ ОК.

Если кривых меньше — «Gordon Surface needs at least 2 profile edges and 2 guide edges.» Если кривые сетки не пересекаются, ядро вернёт ошибку. Это продвинутый инструмент: кривые сетки нужно строить аккуратно, с привязкой к точкам пересечения.

### 5.11. Труба

**«Рисование ▾» → «Труба»**, клавиша **Shift+P** — круглая труба или пруток по ломаной.

1. Щёлкайте точки ломаной оси.
2. **✓ ОК** в панели — построить. (Щелчок по первой точке показывает подсказку «Подтвердить».) **Enter и Esc здесь отменяют команду** — заканчивайте только кнопкой ОК.

Параметр панели: **«Радиус»** — наружный радиус, по умолчанию 5 мм.

Свойства готовой трубы:

| Поле | Что значит |
|---|---|
| **Радиус** | Наружный радиус трубы |
| **Радиус изгиба** | 0 — острые углы; больше 0 — изгибы на этом радиусе (если меньше радиуса трубы, программа берёт радиус трубы + 1 мм) |
| **Толщина** | 0 — сплошной пруток; больше 0 — полая труба с такой стенкой. Толщина должна быть меньше радиуса («Thickness must be less than Radius») |

## 6. Свойства созданного объекта: как поменять размеры

Щёлкните по объекту в окне или в браузере — внизу слева в панели **«СВОЙСТВА»** появятся:

1. **«Имя»** — как объект называется в браузере.
2. Раскрывающийся блок **«Матрица»** — положение объекта: **«Преобразование»** (сдвиг X, Y, Z, мм), **«Масштаб»** (по X, Y, Z), **«Поворот»** (углы в градусах). Значения пишутся тремя числами через запятую.
3. Блок с названием вида объекта («Коробка», «Цилиндр», «Окружность»…) — **«Материал»**, **«Тип фигуры»** и размеры объекта.

Размеры, которые можно менять после создания:

| Объект (как называется в «Свойствах») | Поля |
|---|---|
| Линия | Начало, Конец |
| Прямоугольник | Длина, Ширина, Вперед |
| Окружность | Центр, Радиус, Вперед |
| Элипс | Центр, максимальный Радиус, минимальный Радиус, Вперед |
| Простой Полигон (правильный многоугольник) | Центр, Радиус, Число сторон, Вперед |
| Полигон (многоугольник) | Точки, Вперед |
| Дуга | Центр, Начать, Угол |
| Точка | Положение |
| Спираль | Центр, Радиус, Шаг, Угол |
| Коробка (параллелепипед) | Положение, Длина, Ширина, Высота |
| Сфера | Центр, Радиус |
| Цилиндр, Конус | Центр, Радиус, Высота |
| Пирамида | Длина, Ширина, Высота |
| Призма (выдавливание) | Длина |
| Труба | Радиус, Радиус изгиба, Толщина |
| Text | Положение, Текст, Высота, Depth, Шрифт |

После изменяющей команды (скругление, булева операция и т. п.) объект становится «Редактируемая Фигур» — у него остаются только «Материал» и «Тип фигуры». Если нужно поменять исходный размер — отмените (Ctrl+Z) до этой команды, поправьте размер и повторите.

Если выделено несколько однотипных объектов, поле меняется сразу у всех («Множество значений» — значения у них разные).

## 7. «Изменить»: скругление, фаска, оболочка, обрезка и другие

> **Переместить, Повернуть, Отразить, Массив, Переместить/Копировать, Выровнять, Удалить узел** из этой же группы описаны на странице [Перемещение, измерения, анализ и аннотации](07-modify-and-measure.md).

Все команды ниже открываются из списка **«Изменить ▾»** (значок на панели есть только у «Переместить»; нужные можно вынести на панель, см. [раздел 2](#2-где-кнопки)).

### 7.1. Обрезать (trim)

**«Изменить ▾» → «Обрезать»**, клавиша **T**. Обрезает кривые (отрезки, дуги, окружности — отдельные объекты-рёбра) по пересечениям с другими кривыми.

1. Наведите курсор на кривую: участок, который будет удалён (до ближайших пересечений), подсвечивается.
2. Щёлкните — участок удалён. Кривая разрезается на оставшиеся куски.
3. Обрезайте дальше; закончить — **Esc**. Все обрезки одного запуска отменяются одним Ctrl+Z.

Если кривая ни с чем не пересекается, удаляется целиком. Рёбра тел так не обрезаются — только отдельные кривые.

### 7.2. Extend (удлинить)

**«Изменить ▾» → «Extend»** (подпись английская). Удлиняет (или укорачивает) отрезок или дугу до пересечения с другой кривой — как «Удлинить» в AutoCAD.

1. Выберите кривую, которую удлинять, — щёлкните ближе к тому концу, который должен двигаться («Пожалуйста выберите конечность для удлинения»).
2. Выберите кривую-границу («Пожалуйста выберите граничную конечность»).

Параметр **«Изменить границу»** (включён) — граница тоже удлиняется или подрезается до точки встречи (получается чистый угол); выключен — граница не меняется.

Работает с отрезками и дугами (в том числе рёбрами контура: у контура двигаются только свободные концы). Граница встречается в точке пересечения их продолжений, даже если сама граница до неё не доходит. Дуга не может вырасти в полную окружность.

### 7.3. Оболочка (shell, полое тело)

**«Изменить ▾» → «Оболочка»** — делает тело полым со стенкой заданной толщины и открытыми гранями (коробочка без крышки).

1. Выберите тело («Пожалуйста выберите фигуру») — оно станет полупрозрачным.
2. Щёлкайте грани, которые будут **открыты** («Пожалуйста, выберите стороны для открытия»). Превью стенок обновляется после каждого щелчка.
3. Enter / **✓ ОК**.

Параметры:

| Поле | По умолчанию | Что значит |
|---|---|---|
| **Толщина** | 1 мм | Толщина стенки |
| **Оболочка наружу** | выкл. | Стенка добавляется снаружи (тело становится больше), а не вырезается внутрь |
| **Тип соединения** | Дуга | Как соединяются стенки на внешних углах: «Дуга» (скруглённо) или «Пересечение» (остро) |

Ошибки: «ошибка: Invalid thickness» — толщина 0 или меньше; «ошибка: Select at least one face to open» — не выбрано ни одной грани; ошибка ядра попадает в счётчик «Ошибки» в строке состояния — обычно толщина больше, чем позволяют мелкие элементы тела.

### 7.4. Разделить (split)

**«Изменить ▾» → «Разделить»** — режет фигуру другими фигурами.

1. Выберите, что резать («Пожалуйста выберите фигуру»).
2. Выберите режущие рёбра, контуры или грани (можно несколько), Enter / ✓ ОК.

Если фигура распалась на части, каждая становится отдельным объектом с именем «имя1», «имя2»… Режущие объекты **удаляются**.

### 7.5. Прошить (sew)

**«Изменить ▾» → «Прошить»** — сшивает соседние грани и поверхности в одну оболочку (нужно для импортированных поверхностей перед превращением в тело).

1. Выберите фигуры (или выделите заранее), Enter / ✓ ОК.
2. Получается объект «sewed», исходные удаляются.

Параметр **«Толерантность»** — на каком расстоянии края ещё считаются совпадающими (по умолчанию 0,0000001 мм; для импортированных файлов с зазорами увеличьте, например до 0.01). «ошибка: Invalid tolerance» — значение 0 или меньше.

### 7.6. Упростить

**«Изменить ▾» → «Упростить»** — объединяет лишние грани и рёбра: соседние грани на одной плоскости или цилиндре сливаются в одну, лишние рёбра пропадают. Полезно после булевых операций и импорта STL.

Выберите тело, оболочку или грань. Галочки **«Удалить концы»** (сливать рёбра) и **«Удалить виды»** (сливать грани) — обе включены. Результат называется «имя_simplified».

### 7.7. Скругление (fillet, скруглить рёбра)

**«Изменить ▾» → «Скругление»**, клавиша **Shift+F**.

1. Щёлкайте рёбра одного тела («Пожалуйста выберите конечности»). Если рёбра были выделены заранее, они уже в выборе.
2. Появляется стрелка на первом ребре — **тяните её**, чтобы задать радиус, или введите **«Радиус»** в панели (по умолчанию 10 мм). Превью скругления показывается на полупрозрачном теле.
3. Enter / **✓ ОК**.

Где работает:

- **тело** (3D) — любое число рёбер одного тела;
- **плоская грань, контур или две отдельные линии** (2D) — ровно два соседних ребра, сопряжение в их углу; после второго ребра выбор заканчивается сам.

Ошибки: «Вводите номера, разделенные запятой ','» — радиус 0 или не число; «Пожалуйста, выберите две смежные грани» (в 2D нужно ровно два ребра); если ядро не может построить скругление (радиус больше соседних граней), превью пропадает, а при ОК ошибка попадает в счётчик «Ошибки». Уменьшите радиус.

### 7.8. Фаска (chamfer)

**«Изменить ▾» → «Фаска»**, клавиша **Shift+C**. Всё как у скругления, только поле — **«Длина»** фаски (по умолчанию 10 мм), фаска равносторонняя. Фаски с двумя расстояниями или под углом — на вкладке «Тело» («Тело» → «Изменить» → «Фаска»).

### 7.9. Разбить на части (explode)

**«Изменить ▾» → «Разбить на части»**, клавиша **X** — разбирает объект на составляющие.

- Составной объект или тело из нескольких частей — части становятся отдельными объектами в папке с именем исходного (части называются по типу: «Solid 1», «Face 2»… — по-английски).
- Компонент (группа-блок, см. [раздел 11.2](#112-группа-компонент-блок)) — разворачивается обратно в исходные объекты.
- Тело из одной части — разбивается на его оболочку и т. д. на уровень ниже.

Выберите объекты (или выделите заранее), Enter / ✓ ОК.

### 7.10. Удалить фигуры (удалить грани или рёбра)

**«Изменить ▾» → «Удалить фигуры»** — вынимает из фигуры выбранные грани или рёбра, **не залечивая** дыру (тело может стать незамкнутой оболочкой).

1. Выберите фигуру (не отдельное ребро).
2. Выберите грани или рёбра для удаления, Enter / ✓ ОК.

### 7.11. Удалить функцию (убрать отверстие, скругление, бобышку)

**«Изменить ▾» → «Удалить функцию»** — удаляет элемент формы и **залечивает** место: соседние грани продлеваются и смыкаются. Так убирают отверстие, скругление или выступ у импортированной детали.

1. Выберите тело.
2. Выберите грани элемента — например, все грани отверстия или скругления (только этого тела), Enter / ✓ ОК.

«ошибка: Select at least one face to remove» — грани не выбраны. Если ядро не смогло залечить, ошибка попадает в «Ошибки» — выберите все грани элемента, включая соседние скругления.

### 7.12. Разбить (разрезать кривую в точке)

**«Изменить ▾» → «Разбить»** (в конце списка) — делит одну кривую на две в указанной точке.

1. Выберите кривую («Пожалуйста выберите конечности»).
2. Укажите точку на ней — курсор скользит по кривой.

Получаются «имя_1» и «имя_2». Точка в самом начале или конце кривой ничего не делает.

### 7.13. Внешний вид (покрасить объект)

**«Изменить ▾» → «Внешний вид»** — назначает материал (цвет) целым объектам.

1. Выберите материал в поле **«Материал»** панели.
2. Выберите объекты, Enter / ✓ ОК.

Раскраска отдельных граней при этом сбрасывается. Цвет и другие настройки материала меняются в редакторе материалов — он открывается щелчком по полю «Материал» в «Свойствах» объекта.

### 7.14. Добавить шаблон, Удалить шаблон, Очистить шаблон (покраска граней)

Три команды в конце списка «Изменить ▾» — **кисть для отдельных граней** (в русской версии они подписаны «шаблон»):

- **«Добавить шаблон»** — выберите материал в поле «Материал», щёлкайте грани (можно на разных телах), Enter / ✓ ОК: грани окрашиваются.
- **«Удалить шаблон»** — щёлкайте грани, Enter: их окраска снимается, грань снова цвета объекта.
- **«Очистить шаблон»** — выберите объекты: снимается окраска всех граней.

## 8. «Конвертер»: в контур, грань, оболочку, тело

Группа **«Конвертер»** превращает одни виды фигур в другие. Выделите объекты заранее или выберите их после нажатия («Пожалуйста выберите модели»), Enter / ✓ ОК. Исходные объекты заменяются результатом, в конце — «Успешно». Если ничего не выбрано — «Не выбрано»; если не получилось — «ошибка: …».

| Кнопка | Что принимает | Что получается |
|---|---|---|
| **В контур** | Отрезки, дуги, контуры, соединённые концами | Один контур («Провод») — для выдавливания, сдвига, смещения |
| **В составной объект** | Любые фигуры | Один составной объект «compound» (просто набор, без слияния) |
| **В грань** | Замкнутые плоские кривые или контуры | Плоская грань («Сторона») |
| **В оболочку** | Грани | Оболочка «shell» |
| **В тело** | Замкнутые оболочки | Тело «solid». Мелкие зазоры сначала зашиваются; незамкнутая оболочка в тело не превращается |

Типичный путь «кривые → тело»: нарисовать отрезки → **В контур** → **В грань** → [«Выдавливание»](#56-выдавливание-extrude-призма).

## 9. Булевы операции: объединение, вычитание, пересечение

Группа **«Булевый»** (значков нет — откройте список **«Булевый ▾»**): **«Пересечение»** (клавиша **Shift+I**), **«Вычитание»**, **«Объединение»**.

1. Выберите **основное** тело («Пожалуйста выберите фигуру») — то, из которого вычитают или к которому прибавляют.
2. Выберите одно или несколько тел-**инструментов**. Сразу видно превью результата (основное тело на это время скрывается).
3. Enter / **✓ ОК**.

| Операция | Результат |
|---|---|
| **Объединение** | Тела сливаются в одно |
| **Вычитание** | Из основного вырезаются инструменты (отверстие, паз) |
| **Пересечение** | Остаётся только общий объём |

Параметр **«Хранить инструменты»** (выключен): включите — тела-инструменты останутся на месте (удобно, если ими же вырезать что-то ещё); выключен — инструменты удаляются. Основное тело заменяется результатом («Булевое») в любом случае.

Если операция не удалась — «ошибка: …» в уведомлении; обычно тела не пересекаются или касаются только гранью. Чтобы вычитание оставалось редактируемым, делайте его на вкладке «Тело» («Тело» → «Изменить» → «Вычесть»).

## 10. «Рабочая плоскость»

Группа **«Рабочая плоскость»**: **«Динамическая рабочая плоскость»** (значок на панели; включает рисование прямо на грани под курсором), в списке — **«Задать рабочую плоскость»**, **«Рабочая плоскость по плоскости»**, **«Рабочая плоскость по сечению»**. Все они описаны на [странице 03](03-view-and-selection.md) — там же, как рабочая плоскость влияет на ввод чисел.

## 11. «Инструменты»: проекция, группа, сечение, смещение, копия, проверка

### 11.1. Проекция (кривая на грань)

**«Инструменты» → «Проекция»** — проецирует кривую на грань (например, контур логотипа на изогнутую поверхность).

1. Выберите кривую или контур («Пожалуйста выберите фигуру»).
2. Выберите грань («Пожалуйста выберите стороны»).

Поле **«Направление»** — направление проецирования тремя числами через запятую, по умолчанию `0,0,-1` (сверху вниз по Z). Результат — новая кривая «Проекция» на грани; исходная кривая остаётся.

### 11.2. Группа (компонент, блок)

**«Инструменты» → «Группа»** — объединяет выбранные объекты в **компонент** — единый блок, который потом можно размножать (копии компонента следуют за ним).

1. Выберите объекты (или выделите заранее), Enter / ✓ ОК.
2. Откроется окно «Группа»:
   - **Имя** — имя компонента (по умолчанию «unnamed»);
   - **Точка вставки** — базовая точка компонента: введите `x,y,z` или нажмите кнопку **«Точка вставки»** и щёлкните точку в окне;
   - **Преобразовать экземпляр** (включено) — на месте выбранных объектов остаётся экземпляр компонента. Если выключить, объекты уходят в определение компонента и **пропадают из окна** (найти — в браузере, раздел «Компоненты»).
3. Подтвердите.

Компонент — «замороженная» сетка: внутри него объекты не редактируются. Разобрать обратно — [«Разбить на части»](#79-разбить-на-части-explode).

Что нельзя группировать (объекты просто остаются отдельно, с сообщением): тела, к которым привязаны размеры-аннотации («Узел, измеряемый аннотацией, нельзя группировать — аннотация потеряет ссылку (узел остаётся независимым)»), экземпляры и тела, которые они читают («Linked instances and the bodies they read cannot be grouped — the nodes stay separate»), поглощённые булевы инструменты.

### 11.3. Сечение (линия пересечения двух фигур)

**«Инструменты ▾» → «Сечение»** — строит кривые, по которым пересекаются две фигуры (например, тело и плоскость → контур среза).

1. Выберите первую фигуру (станет полупрозрачной).
2. Выберите вторую фигуру.

Результат — новый объект «Сечение» из рёбер; обе фигуры остаются. (Не путайте с [«Анализ сечения»](07-modify-and-measure.md) — тот только показывает разрез на экране.)

### 11.4. Смещение (offset, эквидистанта)

**«Инструменты ▾» → «Смещение»**, клавиша **O** — параллельная копия кривой, контура или края грани на заданном расстоянии.

1. Выберите ребро, контур или грань (берётся её внешний край).
2. Тяните курсор в сторону или введите расстояние (в строке состояния подсказка «Длина»).

Параметр **«Тип соединения»** — как соединяются смещённые отрезки на углах: **«Дуга»** (скруглённо, по умолчанию), **«Касание»**, **«Пересечение»** (острый угол). Результат — новый объект «Смещение», исходный остаётся.

### 11.5. Копировать фигуру (вынуть грань или ребро)

**«Инструменты ▾» → «Копировать фигуру»** — копирует выбранные **грани или рёбра** тела в отдельные объекты (тело не меняется). Удобно, чтобы взять край грани как профиль или путь.

Выберите грани и/или рёбра, Enter / ✓ ОК. Копии называются по типу («Face», «Edge»), сообщение «Успешно».

### 11.6. Исправить фигуру (repair)

**«Инструменты ▾» → «Исправить фигуру»** (в конце списка) — лечит кривую геометрию (обычно импортированную): зашивает зазоры, исправляет грани и рёбра, убирает мелкие вырожденные грани.

Выберите объекты (или выделите заранее), Enter / ✓ ОК. Параметр **«Толерантность»** — по умолчанию 0,00001 мм; для грязных файлов увеличьте (0.001–0.01). Результат — «имя_repaired», исходный удаляется.

### 11.7. Проверить фигуру (check)

**«Инструменты ▾» → «Проверить фигуру»** — проверяет каждую грань выбранного объекта.

Выберите один объект. Откроется окно «Результат проверки фигуры»:

- «В целом фигура правильная.» — всё хорошо;
- «Фигура содержит оибки на следующих видах:» и таблица: **Вид** (номер грани), **Проверка** («Успешно» / «Не успешно»), **Проверить фигуру** (что именно не так, техническими словами ядра);
- «У фигуры нет видов для проверки.» — у объекта нет граней (например, это кривая).

Если есть ошибки — попробуйте [«Исправить фигуру»](#116-исправить-фигуру-repair), затем проверьте снова.

## 12. «Импорт/Экспорт» и «Остальное»

- **«Импорт/Экспорт»** — кнопки **«Импорт (STL, STEP…)»** и **«Экспорт (STL, STEP…)»**, те же, что в меню **«Файл ▾»**. Подробно — [страница 02](02-files-and-projects.md); про STL и сканы — [STL и сканы → CAD](stl-and-scans.md).
- **«Остальное»** — кнопка **«AI Assistant»** (подпись английская) открывает и закрывает панель ИИ-помощника. Как им пользоваться — [страница 01](01-start-and-interface.md).

## 14. Проблемы и решения

| Что видите | Причина и что делать |
|---|---|
| Нарисованная фигура лежит не в той плоскости | Точки ложатся на рабочую плоскость. Смените её («Рабочая плоскость», [страница 03](03-view-and-selection.md)) или включите динамическую рабочую плоскость и рисуйте прямо на грани |
| Набрал `40` для прямоугольника — получился квадрат не того размера | Одно число — это расстояние от первой точки по направлению к курсору (диагональ). Вводите `длина,ширина`: `40,30` |
| «Не заполнена котрольная точка, нужно только 3 номера» | Первую точку можно задать только щелчком или тремя числами `#x,y,z` |
| Нажал Enter при рисовании трубы — ничего не построилось | У трубы Enter и Esc отменяют. Заканчивайте кнопкой **✓ ОК** в панели |
| После выдавливания пропал исходный эскиз-прямоугольник | Включён «Delete Objects». Выключите его в панели перед выдавливанием, или Ctrl+Z |
| В «Свойствах» пропали длина и ширина | Объект изменили другой командой (скругление, булева…) — он стал простой фигурой. Ctrl+Z до этой команды |
| Скруглил тело с вкладки «Тело» — пропала история | Команды прямого моделирования заменяют параметрическое тело простой фигурой. Ctrl+Z и используйте «Тело» → «Изменить» → «Скругление» |
| Скругление/фаска не строится, превью нет | Радиус больше, чем позволяют соседние грани, или выбраны рёбра разных тел. Уменьшите радиус, скругляйте по частям |
| «ошибка: Select a straight edge as the axis» при вращении | Осью может быть только прямое ребро. Нарисуйте отрезок-ось командой «Линия» |
| Булева операция: «ошибка: …» | Тела не пересекаются, касаются только гранью или одно из них не тело (поверхность). Проверьте «Проверить фигуру», сдвиньте инструмент так, чтобы он заходил внутрь |
| «This body is used by an instance — delete the instance first or make it independent» | С этого тела сняты связанные копии (экземпляры). Удалите экземпляры или сделайте их независимыми («Detach», [страница 07](07-modify-and-measure.md)) |
| После «Группа» объекты пропали из окна | Была выключена галочка «Преобразовать экземпляр». Ctrl+Z и повторите с включённой галочкой |
| Импортированная модель не превращается в тело, булевы операции падают | «Проверить фигуру» → «Прошить» с толерантностью 0.01 → «Исправить фигуру» → «В тело» |
| Не вижу нужной кнопки | Она в списке группы: щёлкните по названию группы со стрелкой ▾ или найдите её поиском команд (S) |

Нашли ошибку — **«Сообщить о проблеме»** на стартовом экране, или пишите в [группу в Telegram](https://t.me/HPA_AirSoft_System_Development/71332).

# Справка Kern3D

Полное руководство пользователя Kern3D. Короткие ответы «где эта кнопка» — в [FAQ](../FAQ.md); все команды и термины по алфавиту — в [указателе](index.md).

Вопросы — в [группе в Telegram](https://t.me/HPA_AirSoft_System_Development/71332) или боту [@kern3D_bot](https://t.me/kern3D_bot) (команда `/guide`). Нашли ошибку — «Сообщить о проблеме» на стартовом экране.

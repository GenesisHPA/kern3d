## 1. Где хранятся документы

Документ Kern3D — это одна модель со всем, что в ней есть: тела, эскизы, история операций, параметры, сборка, чертежи, лазерные задания. Отдельного понятия «проект» (папки с несколькими файлами) нет: то, что на стартовом экране названо **«Недавние проекты»**, — это просто сохранённые документы.

У документа есть **два места хранения**, и их важно не путать:

| | **Хранилище программы** | **Файл `.cd` на диске** |
|---|---|---|
| Команда | **«Сохранить документ»** (Ctrl+S) | **«Сохранить в файл»** |
| Где лежит | Внутри браузера (база IndexedDB этого сайта) или, в настольной программе, в её служебной папке | В папке, которую вы выбрали (или в «Загрузках») |
| Видно в «Недавних проектах» | Да | Нет, пока не откроете файл и не нажмёте «Сохранить документ» |
| Переживёт очистку данных браузера | **Нет** | Да |
| Можно отправить другому человеку | Нет | Да |

Важно знать:

- **Автосохранения нет.** Пока вы не нажали «Сохранить документ» или «Сохранить в файл», изменения есть только в открытом окне.
- Хранилище браузера привязано к **адресу сайта и браузеру**. Документы, сохранённые в Chrome, не видны в Firefox; сохранённые на одном адресе Kern3D не видны на другом; в режиме «Инкогнито» они пропадают при закрытии окна.
- **Настольная программа** (Windows / Linux) хранит документы так же, в своём собственном хранилище (на Windows — в профиле пользователя, обычно `%APPDATA%\Kern3D`). Документы из браузерной версии в ней не видны, и наоборот — переносите их файлом `.cd`.
- Браузер может сам удалить данные сайта, если на диске кончается место. Для важных моделей держите копию в файле `.cd` ([раздел 15](#15-перенос-на-другой-компьютер-и-резервные-копии)).

Рядом с меню — **быстрые значки**: дискета (**«Сохранить документ»**), стрелка вниз (**«Сохранить в файл»**), **«Отменить»** и **«Повторить»**.

## 3. Новый документ

**«Файл ▾» → «Новый документ»**, или **«+»** справа от вкладок документов, или кнопка **«Новый документ»** на стартовом экране.

- Открывается пустой документ в новой вкладке с именем **«Документ 1»**, **«Документ 2»**… Нумерация начинается заново при каждом запуске программы, поэтому в «Недавних проектах» могут оказаться несколько документов с одинаковым именем — это разные документы. Чтобы различать, дайте имя при «Сохранить в файл» ([раздел 5](#5-сохранить-в-файл-cd-сохранить-как)).
- Новый документ **нигде не сохранён**, пока вы не нажмёте «Сохранить документ».
- Если вы импортируете файл, когда ни один документ не открыт, программа сама создаёт документ с именем «Untitled».

## 4. Сохранить документ (Ctrl+S)

**«Файл ▾» → «Сохранить документ»**, значок дискеты в верхней строке, или **Ctrl+S**.

Записывает документ в хранилище программы ([раздел 1](#1-где-хранятся-документы)) и обновляет его карточку в «Недавних проектах»: имя, дату и картинку — снимок текущего вида модели.

- Успех — сообщение **«Документ сохранен»**.
- Ошибка — **«Не удалось сохранить: … Используйте «Сохранить в файл», чтобы не потерять работу.»** Так бывает, когда браузеру не хватает места или хранилище запрещено (например, некоторые приватные режимы). Сразу сохраните файл `.cd`.
- Если не открыт ни один документ — **«Нет активного документа»**.
- Пока идёт сохранение, видна надпись **«Выполнение Сохранить документ»**. Повторное нажатие в это время ничего не делает.
- Сохранение срабатывает, даже если в этот момент работает другая команда.

Сохраняется под тем же «ключом», что и раньше: повторное сохранение перезаписывает ту же карточку, а не создаёт новую.

## 5. Сохранить в файл (.cd, «Сохранить как»)

**«Файл ▾» → «Сохранить в файл»** или значок со стрелкой вниз в верхней строке.

Записывает весь документ в файл с расширением **`.cd`** — его можно перенести на другой компьютер, отправить, хранить как резервную копию.

1. Нажмите **«Сохранить в файл»**.
2. Программа спросит имя:
   - **Chrome, Edge, настольная программа** — системное окно «Сохранить как»: выберите папку и имя. Расширение `.cd` подставится само.
   - **Другие браузеры** (Firefox, Safari) — окно **«Сохранить в файл»** с полем **«Имя»** и кнопками **«Подтвердить»** / **«Отмена»**. После «Подтвердить» файл скачивается в папку загрузок браузера.
3. Появится сообщение **«Загрузка»** — файл записан.

Что ещё нужно знать:

- Если вы ввели **другое имя**, документ переименовывается (как «Сохранить как»): новое имя появится на вкладке. Запрещённые в именах файлов символы `\ / : * ? " < > |` заменяются на `_`, лишнее `.cd` в конце имени убирается.
- «Сохранить в файл» **не записывает** документ в хранилище программы. Чтобы он появился в «Недавних проектах» под новым именем, нажмите ещё и «Сохранить документ».
- «Отмена» в окне выбора имени — ничего не сохраняется.

## 6. Открыть документ (.cd, Ctrl+O)

**«Файл ▾» → «Открыть документ»**, **Ctrl+O**, или кнопка **«Открыть документ»** на стартовом экране.

1. Откроется системное окно выбора файла — в нём видны только файлы **`.cd`**.
2. Выберите файл. Документ откроется в **новой вкладке**, вид подстроится под модель.

- Так открывается только собственный формат Kern3D. Файлы STL, STEP и т. п. — через **«Импорт»** ([раздел 9](#9-импорт-stl-step-iges-brep)).
- Файл `.cd` можно и просто перетащить в окно ([раздел 11](#11-перетаскивание-файлов-в-окно-drag-and-drop)).
- Открытый с диска документ ещё не лежит в хранилище программы. Нажмите «Сохранить документ», если хотите, чтобы он появился в «Недавних проектах».
- Документы, которые вы уже сохраняли «Сохранить документ», открываются со стартового экрана ([раздел 7](#7-недавние-проекты-на-стартовом-экране)).
- Если файл записан другой версией формата, он не откроется — см. [раздел 14](#14-версия-файла-и-совместимость).

## 7. Недавние проекты на стартовом экране

Стартовый экран открывается при запуске, а также по щелчку на **логотип Kern3D** или **значок домика** в верхней строке.

- Слева: кнопки **«Новый документ»**, **«Открыть документ»** и, если документ уже открыт, **«Назад»** (вернуться к модели).
- Справа: список **«Недавние проекты»** — карточки сохранённых документов: картинка (снимок вида при последнем сохранении), имя, дата сохранения. Пока ничего не сохранено, там написано: «Пока нет недавних документов. Создайте или откройте документ, чтобы начать.»

<!-- SHOT 02-home-recents: стартовый экран со списком «Недавние проекты» из 2–3 карточек (картинка, имя, дата) и крестиком удаления на карточке; создать 2–3 документа с телом (runCommand "doc.new", затем "create.box" с кликами в окне), каждый сохранить runCommand "doc.save", затем щёлкнуть логотип Kern3D -->

### 7.1. Открыть недавний документ

Щёлкните по карточке. Документ загрузится из хранилища программы в новую вкладку («Выполнение Открыть документ»). Если он уже открыт — программа просто вернётся к его вкладке.

### 7.2. Удалить документ из списка

Наведите на карточку и нажмите **крестик**. Программа спросит **«Удалить {имя}?»**. После «ОК» документ **удаляется из хранилища программы насовсем** — не только из списка. Если у вас нет его файла `.cd`, восстановить его будет нельзя. Уже открытая вкладка этого документа при этом не закрывается: пока она открыта, его можно сохранить заново.

### 7.3. Переименовать

Отдельной кнопки переименования на карточке нет. Чтобы сменить имя, откройте документ, сделайте **«Сохранить в файл»** с новым именем ([раздел 5](#5-сохранить-в-файл-cd-сохранить-как)), затем **«Сохранить документ»** — карточка обновится под новым именем.

### 7.4. Сколько документов видно

В списке показывается **не больше 20** документов, и порядок не по дате. Если сохранённых документов больше, часть из них в списке может не появиться. Удалите ненужные карточки или храните старые проекты файлами `.cd`.

## 8. Вкладки документов и закрытие

Можно держать открытыми **несколько документов** одновременно. Каждый — вкладка в верхней строке (между быстрыми значками и **«+»**); на вкладке — имя документа и крестик. Щелчок по вкладке переключает на этот документ. После вкладок документов идут вкладки листов чертежа и других редакторов, если они открыты.

<!-- SHOT 02-doc-tabs: верхняя строка с двумя вкладками документов («Документ 1», «Документ 2») и кнопкой «+»; runCommand "doc.new" дважды; кадрировать верхнюю строку окна -->

### 8.1. Закрыть документ

Нажмите **крестик** на вкладке. Программа всегда спрашивает: **«Сохранить изменения в {имя}?»**

- **«ОК»** — документ сохраняется в хранилище программы (как «Сохранить документ») и закрывается.
- **«Отмена»** — документ **закрывается без сохранения**. Это не отмена закрытия!

Вопрос задаётся при каждом закрытии, даже если вы ничего не меняли. Сохранение при закрытии пишет только в хранилище программы, не в файл `.cd`.

### 8.2. Закрыть вкладку браузера или программу

- **Браузер.** Если открыт хотя бы один документ, браузер спросит, точно ли уйти со страницы (его стандартное окно «Покинуть сайт?»). Несохранённые изменения при уходе пропадут.
- **Настольная программа.** Окно **«Закрыть Kern3D?»** — «Несохранённые изменения в открытых документах будут потеряны.» Кнопки **«Закрыть»** и **«Отмена»**.

Перед закрытием сохраните все вкладки.

## 9. Импорт (STL, STEP, IGES, BREP)

**«Файл ▾» → «Импорт (STL, STEP…)»**, или кнопка **«Импорт (STL, STEP…)»** на ленте ([раздел 2](#2-меню-файл)), или перетащите файл в окно.

### 9.1. Какие форматы

| Формат | Расширения | Что получится |
|---|---|---|
| STEP | `.step`, `.stp` | Тела (твердотельная модель, точные грани) |
| IGES | `.iges`, `.igs` | Тела / поверхности |
| BREP (формат ядра OpenCascade) | `.brep` | Тело |
| STL | `.stl` | Тело или сетка — см. ниже |

DXF, SVG, картинки, OBJ, 3MF, PLY в 3D-модель **не импортируются**. SVG, картинки и файлы EzCAD загружаются в редакторе лазера — см. [«Лазер»](10-laser.md).

### 9.2. Как импортировать

1. Нажмите **«Импорт (STL, STEP…)»**. Откроется окно выбора файла — в нём видны только поддерживаемые форматы. Можно выбрать **несколько файлов** сразу.
2. Модель добавляется **в текущий документ** (если документа нет — создаётся новый). Каждый файл — отдельный элемент в дереве, с именем файла.
3. Идёт окно прогресса с этапами:
   - «Файл 1 из 2: чтение …»
   - «Файл 1 из 2: построение тела из … — для большого файла до нескольких минут, окно может не отвечать»
   - «Файл 1 из 2: отображение …»
4. После импорта вид подстраивается под модель.

- Кнопка **«Отмена»** в окне прогресса останавливает импорт перед следующим файлом («Остановлено — ничего не изменено»). Один большой файл посреди построения прервать нельзя — дождитесь.
- Весь импорт — **одно действие**: **Ctrl+Z** («Отменить») убирает всё, что пришло из файлов.
- Импортированное тело сразу становится **параметрическим**: к нему можно применять отверстия, вырезы, скругления и другие операции вкладки «Тело».
- Если файл не прочитался — сообщение **«Неподдержтваемый тип файла: {имя}»** (именно с такой опечаткой). Оно появляется и тогда, когда расширение правильное, но файл повреждён или программа не смогла его разобрать.

**Единицы.** Kern3D работает в **миллиметрах**. STEP и IGES хранят свои единицы внутри файла и пересчитываются при чтении. В STL единиц нет: числа из файла читаются как миллиметры. Если STL из программы, работавшей в дюймах, пришёл в 25,4 раза меньше — увеличьте его масштабированием (см. [«Изменение и измерение»](07-modify-and-measure.md)).

### 9.3. STL: тело или сетка

Коротко: STL **до 100 000 треугольников** превращается в **тело** (грани сшиваются, плоские участки объединяются, отверстия распознаются как цилиндры), **больше** — открывается **сеткой** для инструментов «Скан». Подробно, что с этим делать дальше, — в [«STL и сканы → CAD», раздел 2](stl-and-scans.md#2-импорт-stl-тело-или-сетка).

## 10. Экспорт (STL, STEP, IGES, BREP, 3MF, OBJ, PLY)

**«Файл ▾» → «Экспорт (STL, STEP…)»** или кнопка **«Экспорт (STL, STEP…)»** на ленте ([раздел 2](#2-меню-файл)).

Экспорт выгружает **выбранные тела**, а не весь документ. Чтобы сохранить документ целиком для Kern3D, используйте «Сохранить в файл».

### 10.1. Как экспортировать

1. Выделите тела, которые нужно выгрузить (в окне или в дереве; несколько — с Ctrl или рамкой). Можно и не выделять заранее.
2. Нажмите **«Экспорт (STL, STEP…)»**. Над окном модели появится панель команды с полями **«Формат»** и **«Merge»**, а в строке подсказки — **«Пожалуйста выберите модели»**.
3. Выберите формат и при необходимости снимите «Merge».
4. Если тела не выделены — щёлкните по ним в окне. Счётчик **«Выбрано»** показывает, сколько выбрано.
5. Нажмите **«ОК»**. Появится «Загрузка», и браузер скачает файл (в настольной программе — спросит, куда сохранить).

**«Отмена»** — выйти без экспорта. Если ничего не выбрано — сообщение **«Не выбрано»**.

### 10.2. Поля панели

| Поле | Что значит | По умолчанию |
|---|---|---|
| **Формат** | Формат файла (список ниже) | `.step` |
| **Merge** (объединить) | Включено — все выбранные тела в **один файл**. Выключено — каждое тело в **отдельный файл**, все они упаковываются в один архив `.zip` (браузер не даёт скачать много файлов сразу) | Включено |

Имя файла — по **первому выбранному телу**: `Тело.step`, `Тело.zip`. Одинаковые имена внутри архива получают `-1`, `-2`…

### 10.3. Форматы экспорта

| В списке «Формат» | Что это | Для чего |
|---|---|---|
| `.step` | STEP, точная твердотельная модель | Другие CAD: Fusion, SolidWorks, Компас, FreeCAD |
| `.iges` | IGES, точная модель (старый формат) | Старые CAD и CAM |
| `.brep` | BREP ядра OpenCascade | FreeCAD и программы на OpenCascade |
| `.stl` | STL, **текстовый** (ASCII) | Печать; файл больше по размеру |
| `.stl binary` | STL, **двоичный** — расширение файла тоже `.stl` | **3D-печать** — обычный выбор для слайсера |
| `.3mf` | 3MF, каждое тело — отдельный объект, в миллиметрах | Слайсеры (PrusaSlicer, Bambu Studio, Cura) |
| `.obj` | OBJ, сетка треугольников | Визуализация, Blender |
| `.ply` | PLY, текстовый | Программы для сеток и сканов |
| `.ply binary` | PLY, двоичный — расширение `.ply` | То же, файл меньше |

Что нужно знать:

- **Единицы — миллиметры.** Размеры выгружаются в мировых координатах, с учётом всех перемещений и поворотов.
- **STL и 3MF** строятся по той же сетке треугольников, что видна на экране. Отдельной настройки точности (размера треугольников) нет.
- Опорная геометрия (плоскости, оси, точки) не экспортируется.
- **Сетки** (большие STL и сканы, открытые сеткой) экспортируются только в **OBJ и PLY**. В STL, STEP, IGES, BREP, 3MF сетка не попадёт — будет сообщение «Нет нод для экспорта». Чтобы получить из скана STL или STEP, сначала сделайте из него тело ([«STL и сканы → CAD»](stl-and-scans.md)).
- Выбирайте **сами тела**, а не папку в дереве: папка в экспорт не попадает.
- Чертежи (DXF, PDF, SVG) экспортируются в редакторе чертежа — см. [«Чертежи»](09-drawings.md). G-code для лазера и фрезера — на страницах [«Лазер»](10-laser.md) и [«Фрезеровка»](12-milling-cam.md).

## 11. Перетаскивание файлов в окно (drag-and-drop)

Перетащите один или несколько файлов из проводника в окно Kern3D. Программа сама разберёт их по расширению:

- **`.cd`** — открывается как документ в новой вкладке (как «Открыть документ»);
- **`.chiliplugin`** — загружается как плагин ([раздел 13](#13-плагины-chiliplugin));
- **всё остальное** — импортируется в текущий документ (как «Импорт»). Неподдерживаемый файл даст «Неподдержтваемый тип файла: …».

Можно бросить в окно сразу смесь: документы откроются, модели импортируются.

## 12. Открытие модели по ссылке (?url=, ?model=)

Kern3D умеет при запуске сам загрузить файл по ссылке. Добавьте к адресу программы параметр:

```
https://<адрес Kern3D>/?url=https://example.com/models/bracket.step
```

- Подходит **`?url=`** или **`?model=`** (то же самое).
- Файл обрабатывается как при перетаскивании: `.cd` открывается документом, STL/STEP/IGES/BREP импортируются.
- В конце ссылки должно стоять **имя файла с расширением** — по нему программа понимает формат.
- Сервер, с которого берётся файл, должен разрешать загрузку с других сайтов (CORS). Если не разрешает или ссылка неверна, **ничего не откроется и сообщения не будет** — скачайте файл и откройте его вручную.

Так удобно делиться моделью: выложите `.cd` или `.step` на свой сервер и отправьте ссылку.

## 13. Плагины (.chiliplugin)

Плагин добавляет в программу новые команды. Это файл **`.chiliplugin`** (zip-архив с описанием `manifest.json` и кодом). Плагины пишут сторонние разработчики; загружайте только те, которым доверяете — плагин выполняет свой код внутри программы.

Как загрузить:

- **Файлом** — перетащите `.chiliplugin` в окно Kern3D.
- **По ссылке при запуске** — параметр **`?plugin=`** в адресе, можно несколько: `?plugin=https://site/a/&plugin=https://site/b/`. Его можно сочетать с `?url=`.

Если плагин загружается с чужого сайта, программа спросит: окно **«Внимание»** — **«Вы доверяете скриптам из этих источников?»** и адрес сайта. **«Доверять»** — загрузить и запомнить этот сайт (в следующий раз без вопроса). **«Не доверять»** — не загружать (до перезагрузки страницы с этого сайта больше не спросит).

<!-- SHOT 02-plugin-trust: окно «Внимание» с текстом «Вы доверяете скриптам из этих источников?», адресом сайта и кнопками «Не доверять» / «Доверять»; открыть Kern3D с адресом `?plugin=https://example.com/plugin/` -->

- Плагин работает до перезагрузки страницы. Чтобы он был всегда, открывайте Kern3D по ссылке с `?plugin=` (например, из закладки).
- Отдельного окна со списком плагинов нет.
- Ошибки плагинов показываются по-английски, например «Plugin … already loaded» (уже загружен), «manifest.json not found in plugin archive» (архив не является плагином).

## 14. Версия файла и совместимость

Каждый документ хранит **версию формата** (сейчас **0.7.1**). Она меняется, только когда меняется устройство файла, а не с каждым выпуском программы. Kern3D открывает **только документы своей версии формата** — автоматического преобразования старых файлов нет.

Если версия не совпадает, появляется окно (по-английски):

> The file version has been upgraded, no compatibility treatment was done in the development phase

Это значит: «формат файла изменился, совместимость со старой версией не поддерживается». Документ не открывается — ни из файла `.cd`, ни со стартового экрана. Ваш файл при этом не повреждается.

Что делать:

- Файл, сохранённый **более новой** версией Kern3D, — обновите программу (настольная обновляется сама; в браузере обновите страницу).
- Файл **старой** версии формата текущая программа не откроет. Если модель нужна, откройте её в той версии Kern3D, в которой она сделана, и выгрузите тела в **STEP** — его можно импортировать в любую версию (история операций при этом не сохраняется).
- Для долгого хранения держите рядом с `.cd` экспорт в STEP.

## 15. Перенос на другой компьютер и резервные копии

- **Перенос:** на старом компьютере — «Сохранить в файл» → перенесите `.cd` (флешка, почта, облако) → на новом — «Открыть документ» или перетащите файл в окно → «Сохранить документ», чтобы он появился в «Недавних проектах».
- **Между браузером и настольной программой** — точно так же, через файл `.cd`.
- **Резервная копия:** регулярно делайте «Сохранить в файл» для важных проектов. Хранилище браузера — не надёжное место: его стирает очистка истории («Файлы cookie и другие данные сайтов»), переустановка браузера, режим «Инкогнито», а иногда и сам браузер при нехватке места.
- **Другому человеку в другой CAD** — экспорт в STEP; **для печати** — STL или 3MF.

## 16. Проблемы и решения

| Что видите | Причина и что делать |
|---|---|
| Пропали все проекты из «Недавних» | Очищены данные браузера, другой браузер, другой адрес сайта или режим «Инкогнито». Из хранилища их не вернуть — откройте файлы `.cd`, если вы их сохраняли. Дальше — регулярно «Сохранить в файл» |
| Документ из браузера не виден в настольной программе (и наоборот) | У них разные хранилища. Перенесите файлом `.cd` ([раздел 15](#15-перенос-на-другой-компьютер-и-резервные-копии)) |
| Сохранённого документа нет в «Недавних проектах» | Показывается не больше 20 документов. Удалите ненужные карточки. Или документ сохраняли только «Сохранить в файл» — откройте файл и нажмите «Сохранить документ» |
| «Не удалось сохранить: …» | Нет места или браузер запрещает хранилище. Сразу «Сохранить в файл», освободите место на диске |
| «The file version has been upgraded…» | Файл другой версии формата ([раздел 14](#14-версия-файла-и-совместимость)) |
| «Открыть документ» не показывает мой STL/STEP | «Открыть документ» — только для `.cd`. Модели из других программ — через «Импорт» |
| «Неподдержтваемый тип файла: …» | Формат не поддерживается (DXF, OBJ, 3MF, SVG не импортируются в 3D) или файл повреждён. Пересохраните его в исходной программе в STEP или STL |
| Большой STL / STEP грузится долго, окно не отвечает | Нормально: построение тела — одна долгая операция. Дождитесь шкалы. STL больше 100 000 треугольников открывается сеткой ([подробнее](stl-and-scans.md#2-импорт-stl-тело-или-сетка)) |
| Модель после импорта крошечная или огромная | В STL нет единиц. Файл в дюймах — увеличьте в 25,4 раза; в метрах — в 1000 раз |
| «Нет нод для экспорта» | Выбрана сетка, папка или опорная геометрия. Выберите тела; сетку можно выгрузить только в OBJ / PLY |
| «Не выбрано» / «Модель не выбранна» при экспорте | Не выбрано ни одного тела. Выделите тела и нажмите «ОК» |
| Скачался `.zip` вместо одного файла | Выключено «Merge» при нескольких телах. Включите «Merge», чтобы получить один файл |
| Нажал «Отмена» при закрытии вкладки — работа пропала | «Отмена» в вопросе «Сохранить изменения в …?» значит «закрыть без сохранения». Если документ раньше сохранялся, откройте его последнюю сохранённую версию со стартового экрана |
| Ссылка `?url=` ничего не открыла | Сервер не разрешает загрузку (CORS) или в ссылке нет имени файла с расширением. Скачайте файл и перетащите в окно |
| Не загружается плагин | Нажмите «Доверять» в окне «Внимание»; проверьте, что это `.chiliplugin` с `manifest.json`. Уже загруженный плагин второй раз не загружается — обновите страницу |

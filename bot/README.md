# Telegram-бот Kern3D

Бот для группы Kern3D:

- отвечает на вопросы поиском по частым вопросам (`kb/faq.md`), README, журналу изменений и списку команд программы — без ИИ, только готовые тексты;
- публикует новый релиз (версия, дата, что нового, ссылки на скачивание) в подписанные чаты;
- команды `/version`, `/download`, `/changes [версия]`, `/faq [номер]`, `/search <текст>`, `/here`, `/stop`, `/help`.

Node.js 22 без зависимостей. Работает через long polling: наружу ничего не открывается, входящие порты не нужны.

## Установка на сервер

1. В Telegram откройте @BotFather → `/newbot`, задайте имя и username (например `kern3d_bot`). Скопируйте токен.
2. Скопируйте папку `bot/` на сервер, например в `/opt/kern3d-bot`:
   ```bash
   scp -r bot/ user@server:/opt/kern3d-bot
   ```
3. На сервере создайте `.env` с токеном:
   ```bash
   cd /opt/kern3d-bot
   cp .env.example .env
   nano .env            # TELEGRAM_BOT_TOKEN=123456:ABC...
   chmod 600 .env
   ```
4. Запустите:
   ```bash
   docker compose up -d --build
   docker compose logs -f kern3d-bot   # должно быть «started as @...»
   ```
5. Добавьте бота в группу. Администратор группы пишет в ней `/here` — с этого момента туда приходят новости о релизах. `/stop` — отписать группу. В личке `/here` подписывает лично вас.

Состояние (подписанные чаты, последний объявленный релиз, позиция в очереди сообщений) лежит в томе `kern3d-bot-data` (`/data/state.json` в контейнере) и переживает пересборку.

При самом первом запуске бот только запоминает текущий релиз и ничего не публикует. Следующий релиз появится в подписанных чатах в течение 10 минут (`RELEASE_POLL_MINUTES` в `.env`).

## Обновление

```bash
cd /opt/kern3d-bot
# заменить файлы новой версией папки bot/ (кроме .env), затем
docker compose up -d --build
```

README и CHANGELOG бот берёт с GitHub (ветка main) при запуске и после каждого нового релиза; если GitHub недоступен — использует копии из `kb/`. FAQ и список команд — только из `kb/`, поэтому после их правки нужна пересборка.

## Когда бот отвечает в группе

- на команды (`/faq`, `/version`, …);
- если его упомянули (`@kern3d_bot как сделать резьбу`);
- если ответили на его сообщение;
- если сообщение начинается со знака «?» (`? левая резьба`).

Остальные сообщения бот молча пропускает — в группе он не спамит. В личке любое сообщение считается вопросом.

### Режим приватности (/setprivacy)

По умолчанию у ботов включён режим приватности: в группе бот получает только команды, упоминания и ответы на свои сообщения. Для первых трёх пунктов этого достаточно — режим можно оставить включённым.

Сообщения, которые начинаются с «?», при включённом режиме до бота **не доходят**. Чтобы они работали, в @BotFather: `/setprivacy` → выбрать бота → **Disable**. После этого удалите бота из группы и добавьте снова (Telegram применяет настройку при добавлении). Бот получает все сообщения группы, но отвечает по-прежнему только по правилам выше и ничего не сохраняет, кроме номера последнего обработанного сообщения.

## Разработка

```bash
cd bot
node --test "test/*.test.mjs"        # тесты, без сети
node scripts/build-commands.mjs      # обновить kb/commands.json и копии README/CHANGELOG
TELEGRAM_BOT_TOKEN=... DATA_DIR=./data node src/main.mjs
```

`kb/commands.json` генерируется из `packages/i18n/src/ru.ts` и раскладок ленты (`packages/builder/src/ribbon.ts`, `packages/parametric/src/sketch/ribbon.ts`) — запускайте скрипт после изменения команд. В `kb/faq.md` каждый вопрос — заголовок `##`; строка `<!-- ключи: ... -->` добавляет слова для поиска и не показывается. Пишите в FAQ только то, что есть в программе.

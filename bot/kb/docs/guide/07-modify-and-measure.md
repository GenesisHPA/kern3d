## 1. Где кнопки

Переключатель рабочих пространств — **«Конструирование»**. Значки над названием группы — только у самых частых команд, остальные открываются из списка группы (щелчок по названию группы со стрелкой ▾, см. [страницу 06](06-direct-modeling.md#2-где-кнопки)).

| Команда | Вкладка «Тело» | Вкладка «Прямое моделирование» |
|---|---|---|
| Переместить | «Сборка ▾» | «Изменить» (значок) |
| Повернуть, Отразить, Массив | «Сборка ▾» | «Изменить ▾» |
| Переместить/Копировать | «Сборка» (значок) | «Изменить ▾» |
| Выровнять | «Сборка» (значок) | «Изменить ▾» |
| Detach (сделать независимым) | «Сборка ▾» | — (и кнопка в «Свойствах» экземпляра) |
| Удалить узел | «Изменить ▾» | «Изменить ▾» |
| Длина | «Анализ» (значок) | «Измерение ▾» |
| Угол (измерение), Измерить выбранное | «Анализ ▾» | «Измерение ▾» |
| Анализ сечения | «Анализ» (значок) | «Анализ» (значок) |
| Пересечения тел, Массовые свойства | «Анализ ▾» | «Анализ ▾» |
| Размер | «Анализ ▾» | «Аннотация» (значок) |
| Радиус, Диаметр, Угол (размер) | «Анализ ▾» | «Аннотация ▾» |
| Текст (аннотация) | «Анализ ▾» | «Аннотация» (значок) |
| Выровнять камеру | — | «Акт» (значок) |

> В списке «Тело» → «Анализ ▾» две строки «Угол»: первая (выше) — **измерение** угла по трём точкам, вторая (рядом с «Радиус», «Диаметр») — **размер-аннотация** угла между рёбрами.

Все команды находятся и поиском команд (клавиша **S**).

## 2. Перемещение, поворот, отражение

Общее для «Переместить», «Повернуть», «Отразить»:

- Двигаются **целые объекты** (тела, кривые, компоненты, аннотации). Если объекты выделены заранее — команда берёт их; иначе попросит «Пожалуйста выберите модели» (выбор щелчками или рамкой, Enter / ✓ ОК).
- Галочка **«Клон»** в панели — вместо перемещения создаётся **копия** на новом месте, оригинал остаётся.
- Во время команды контур объектов показывается там, куда они встанут.
- **Тело с вкладки «Тело»** при перемещении не теряет историю: перемещение записывается в его список операций как отдельная операция (видна на шкале истории).
- **Эскизы и опорная геометрия** (плоскости, оси, точки построения) так не двигаются: «This node is input geometry and cannot be moved — edit it directly» (сообщение по-английски). Их редактируют сами по себе.
- Поглощённые булевыми операциями инструменты двигать нельзя: «Поглощённые булевы инструменты нельзя копировать, перемещать или удалять — редактируйте их через список операций тела-владельца».
- Если размер-аннотация была привязана к геометрии, а вы переместили саму аннотацию, привязка снимается (аннотация остаётся там, куда её поставили).

### 2.1. Переместить (move, сдвинуть)

**«Прямое моделирование» → «Изменить» → «Переместить»** или **«Тело» → «Сборка ▾» → «Переместить»**, клавиша **M**.

1. Выберите объекты (или выделите заранее).
2. Базовая точка («выберите точку начала, ESC для отмены») — например, угол детали (работают привязки).
3. Куда её перенести («выберите следующую точку, ESC для отмены») — щелчком или числами: `20` — на 20 мм в сторону курсора, `20,0,5` — на 20 по X и 5 по Z, `#0,0,0` — в начало координат.

### 2.2. Повернуть (rotate)

**«Изменить ▾» → «Повернуть»** (или «Тело» → «Сборка ▾»), клавиша **Shift+R**.

1. Выберите объекты.
2. Центр поворота.
3. Вторая точка — от неё отсчитывается угол (луч «ноль градусов»).
4. Третья точка — конечный угол, или введите угол в градусах (`90`, `-45`).

Поворот идёт вокруг оси, перпендикулярной рабочей плоскости и проходящей через центр (при динамической рабочей плоскости — перпендикулярной грани, на которой взята вторая точка). Чтобы повернуть вокруг другой оси, смените рабочую плоскость ([страница 03](03-view-and-selection.md)) или используйте [«Переместить/Копировать»](#24-переместитькопировать-точно-по-числам) с углами вокруг X, Y, Z.

### 2.3. Отразить (mirror, зеркало)

**«Изменить ▾» → «Отразить»** (или «Тело» → «Сборка ▾»).

1. Выберите объекты.
2. Две точки линии отражения в рабочей плоскости (по ним видна длинная линия).

Объекты отражаются относительно плоскости, проходящей через эту линию перпендикулярно рабочей плоскости. Без галочки **«Клон»** объект просто переворачивается зеркально на месте; с «Клон» — появляется зеркальная копия (так делают симметричные детали).

### 2.4. Переместить/Копировать (точно по числам)

**«Тело» → «Сборка» → «Переместить/Копировать»** или **«Прямое моделирование» → «Изменить ▾» → «Переместить/Копировать»** — перемещение и поворот вводом чисел, как Move в Fusion 360.

1. Выберите объекты (или выделите заранее), Enter.
2. Объекты «висят» в новом положении полупрозрачно; на них — три стрелки (X — красная, Y — зелёная, Z — синяя). Подсказка: «Введите смещения и углы, затем подтвердите».
   - Потяните **стрелку** — сдвиг вдоль её оси; потяните за любое другое место — сдвиг в плоскости, повёрнутой к экрану. Сдвиг мышью идёт с шагом 0,1 мм.
   - Или введите числа в панели.
3. **Enter** или **✓ ОК** — применить; **Esc** — отменить.

| Поле панели | Что значит |
|---|---|
| **Смещение X / Y / Z** | Сдвиг по осям мира, мм |
| **Поворот X / Y / Z** | Поворот вокруг осей мира X, затем Y, затем Z, в градусах |
| **Указать центр поворота** | Выключено — поворот вокруг центра габаритов выбранного; включено — команда попросит «Укажите центр поворота» |
| **Клон** | Сделать копию, оригинал оставить |

В полях можно писать выражения с переменными документа (`width/2`). Если выражение не считается, появится «ошибка: …», и превью пропадёт до исправления.

### 2.5. Выровнять (align, поставить деталь на деталь)

**«Тело» → «Сборка» → «Выровнять»** или **«Прямое моделирование» → «Изменить ▾» → «Выровнять»** — ставит одну деталь на другую по выбранной геометрии.

1. Щёлкните грань, ребро или вершину на **перемещаемой** детали («Выберите грань, ребро или вершину на перемещаемой детали»).
2. Щёлкните грань, ребро или вершину на **неподвижной** детали («Выберите грань, ребро или вершину, к которой выровнять»).
3. Деталь встаёт на место полупрозрачно («Настройте выравнивание и подтвердите»). Поправьте параметры и нажмите **Enter** / **✓ ОК**.

Как выравнивается:

| Что выбрано | Результат |
|---|---|
| Две плоские грани | Грани прижимаются друг к другу (вплотную, лицом к лицу) |
| Два прямых ребра или две цилиндрические грани | Оси совмещаются (на одной прямой) |
| Две окружности (круглые рёбра) | Соосно и в одной плоскости |
| Вершина с любой стороны | Простой перенос: точка на точку |

| Поле панели | Что значит |
|---|---|
| **Перевернуть** | Развернуть деталь на 180° (другой стороной) |
| **Угол** | Дополнительный поворот вокруг оси выравнивания, градусы |
| **Привязка к центру грани** | Включено — совмещаются центры граней; выключено — точки, где вы щёлкнули |
| **Клон** | Поставить копию, оригинал оставить |

Для сборок с подвижными соединениями используйте сочленения ([страница 08](08-assembly.md)).

## 3. Массив (размножить копии)

**«Прямое моделирование» → «Изменить ▾» → «Массив»** или **«Тело» → «Сборка ▾» → «Массив»**, клавиша **Shift+A**.

1. Выберите объекты (или выделите заранее).
2. В панели выберите **«Тип шаблона»** (смена типа перезапускает шаги).
3. Укажите точки (см. ниже) — во время указания видны контуры всех копий.

Исходный объект становится первым элементом массива. Общие поля:

| Поле | Что значит |
|---|---|
| **Тип шаблона** | «По линии», «По кругу», «По кривой», «По прямоугольнику» |
| **Количество** | Сколько всего элементов вместе с исходным (по умолчанию 3) |
| **Общая длина** | Для «По линии» и «По кругу»: выключено — указанное расстояние/угол — это шаг между соседями; включено — это расстояние/угол от первого до последнего |
| **Группа** | Включено (по умолчанию) — весь массив становится одним компонентом «Array» (блоком). Выключено — отдельные объекты |

> Массив с «Группа» — это «замороженный» блок: чтобы править копии по отдельности, разберите его командой «Разбить на части» ([страница 06](06-direct-modeling.md#79-разбить-на-части-explode)) или делайте массив с выключенной «Группа». Если среди объектов есть связанные экземпляры, группа не создаётся: «Linked instances and the bodies they read cannot be grouped — the nodes stay separate».

Параметрические массивы, которые пересчитываются вместе с телом (линейный, круговой, по кривой), — на вкладке «Тело» в группе «Создать» ([страница 05](05-body-parametric.md)).

### 3.1. По линии

1. Первая точка.
2. Вторая точка — направление и шаг (или общая длина): щелчком или числом, например `25`.

### 3.2. По кругу (круговой массив)

1. Центр массива («выберите центр, ESC для отмены»).
2. Точка, от которой отсчитывается угол.
3. Угол — щелчком или числом в градусах. Без «Общая длина» это угол **между соседними** копиями (для 6 отверстий по кругу: Количество 6, угол 60); с «Общая длина» — угол от первой до последней.

Ось — перпендикуляр к рабочей плоскости. Поле **«Смещение по нормали»** — каждая следующая копия дополнительно сдвигается вдоль оси на это расстояние (получается «винтовая лестница»).

### 3.3. По кривой

Выберите кривую («Пожалуйста выберите кривые»). Копии расставляются **равномерно по длине кривой** и только сдвигаются (не поворачиваются по касательной). Сдвиг отсчитывается от начала кривой — поставьте исходный объект в начало кривой.

### 3.4. По прямоугольнику (сетка)

Поля **«Число X»**, **«Число Y»**, **«Число Z»** (по 3) — сколько копий по каждому направлению; всего копий = X × Y × Z.

1. Первая точка.
2. Вторая точка — направление X и шаг по нему.
3. Третья точка — шаг по Y (поперёк, в рабочей плоскости).
4. Четвёртая точка — шаг по Z (вверх).

Для плоской сетки поставьте **Число Z = 1** — четвёртую точку всё равно нужно указать (любую).



## 4. Удалить узел и Detach

### 4.1. Удалить узел (удалить объект)

**«Изменить ▾» → «Удалить узел»** на любой из двух вкладок, клавиши **Delete** или **Backspace**. Удаляет выделенные объекты (или те, что вы выберете). Можно удалять и опорные плоскости — то, что на них ссылалось, покажет предупреждение. Удаление папки удаляет всё внутри.

Сообщения: «Удалено N объектов»; «Не выбрано»; «This body is used by an instance — delete the instance first or make it independent» — тело нельзя удалить, пока с него сняты связанные экземпляры (удалите экземпляры вместе с ним или сделайте их независимыми); «Поглощённые булевы инструменты нельзя…» — инструмент булевой операции удаляют через список операций тела. Отменить — Ctrl+Z.

### 4.2. Detach (сделать экземпляр независимым)

**«Тело» → «Сборка ▾» → «Detach»** (подпись английская), или кнопка **«Detach»** в «Свойствах» выбранного экземпляра — рядом со ссылкой на исходное тело.

Экземпляр — связанная копия, которая повторяет изменения исходного тела. Detach превращает его в обычное независимое тело на том же месте: со своим списком операций и своими копиями эскизов. Дальше исходное тело и бывший экземпляр меняются отдельно. Работает с одним экземпляром за раз; если выбран не экземпляр — «ошибка: Select an instance». Подробнее об экземплярах и компонентах — [страница 08](08-assembly.md).

## 5. Измерения: длина, угол, площадь, объём

Результаты измерений — **временные метки** на экране: в документ они не сохраняются и на чертёж не попадают. Для постоянных размеров — [аннотации](#7-аннотации-размеры-и-текст-в-3d).

### 5.1. Размер при наведении

Без всякой команды наведите курсор на ребро — рядом появится его размер: длина прямого ребра, **Ø** полной окружности, **R** и длина дуги. На цилиндрической грани — её Ø. Это самый быстрый способ узнать диаметр отверстия.

### 5.2. Длина (расстояние между точками)

**«Тело» → «Анализ» → «Длина»** или **«Прямое моделирование» → «Измерение ▾» → «Длина»**, клавиша **D**.

1. Первая точка, вторая точка (привязки к вершинам, серединам, центрам работают).
2. Между точками рисуется линия и подпись — расстояние в мм с двумя знаками после запятой (прямое расстояние в пространстве).

Метка остаётся на экране; убрать — **×** на метке. Команда заканчивается после одного измерения — для следующего нажмите кнопку снова (или пробел — повтор последней команды).

### 5.3. Угол (измерить угол по трём точкам)

**«Тело» → «Анализ ▾» → «Угол»** (первый в списке) или **«Прямое моделирование» → «Измерение ▾» → «Угол»**.

1. **Вершина угла** — первая точка.
2. Точка на первой стороне.
3. Точка на второй стороне — возле курсора виден угол.

Остаётся дуга с подписью вида `90.00°`; убрать — ×.

### 5.4. Измерить выбранное (длина рёбер, площадь граней, объём тел)

**«Тело» → «Анализ ▾» → «Измерить выбранное»** или **«Прямое моделирование» → «Измерение ▾» → «Измерить выбранное»** — считает и **суммирует**.

1. В панели выберите **«Тип»**: **«Длина»** (рёбра), **«Область»** (площадь граней) или **«Объем»** (тела).
2. Щёлкайте рёбра / грани / тела по одному (подсказки «Пожалуйста выберите конечности», «Пожалуйста выберите стороны», «Пожалуйста выберите массивы» — так в программе называются рёбра, грани и тела).
3. На каждом выбранном — подпись со значением; в углу окна — карточка со списком значений и **суммой**.
4. **Esc** — закончить; подписи и карточка исчезают. Смена «Тип» начинает подсчёт заново.

Единицы: длина — мм, площадь — мм², объём — мм³ (на экране единицы не пишутся). Так удобно узнать длину реза по контуру, площадь под покраску или объём материала.



## 6. Анализ: сечение, пересечения тел, масса

Эти инструменты **ничего не меняют в модели** — только показывают.

### 6.1. Анализ сечения (разрез на экране)

**«Анализ» → «Анализ сечения»** (значок на обеих вкладках). Разрезает вид плоскостью: всё по одну сторону скрыто, срезы тел залиты красным — видно стенки, полости, отверстия внутри.

1. В панели выберите **«Плоскость»**:
   - **«Выбранная грань / плоскость»** — затем щёлкните плоскую грань или опорную плоскость («Пожалуйста выберите стороны»);
   - **«Рабочая плоскость»**, **«Плоскость XY»**, **«Плоскость YZ»**, **«Плоскость ZX»** — плоскость берётся сразу.
2. Двигайте курсор — плоскость разреза едет вдоль своей нормали («Перетащите или введите смещение сечения, Esc — завершить»); щелчок фиксирует положение, можно ввести число.
3. **Esc** — закончить команду. **Разрез остаётся на экране.**
4. Чтобы **выключить** разрез — нажмите «Анализ сечения» ещё раз: «Анализ сечения выключен». Также разрез включается и выключается кнопкой **«Сечение вкл/выкл»** на панели вида внизу окна ([страница 03](03-view-and-selection.md)).

| Поле | Что значит |
|---|---|
| **Плоскость** | Откуда взять плоскость разреза (см. выше) |
| **Смещение** | Сдвиг плоскости вдоль нормали, мм |
| **Развернуть** | Показывать другую половину |
| **Заливка среза** | Заливать срез красным (включено). Выключите, если тел много и разрез двигается медленно |

Разрез ничего не сохраняет в документе. На чертеже разрезы делаются отдельно ([страница 09](09-drawings.md)).

![«Анализ сечения»: выбрана грань, панель параметров](images/07-section-analysis.png)

### 6.2. Пересечения тел (интерференция, проверка сборки)

**«Анализ ▾» → «Пересечения тел»** — находит тела, которые залезают друг в друга (болт не проходит в отверстие, крышка шире корпуса).

1. Выберите **два или больше** тела (или выделите заранее), Enter / ✓ ОК. Если тело одно — «Выберите хотя бы два тела».
2. Общие объёмы закрашиваются **красным** поверх модели (видно даже внутри).
3. В углу окна — карточка «Пересечения тел»: **«Проверено тел»**, **«Пересекающихся пар»** и по строке на каждую пару: «Тело1 ↔ Тело2 — объём mm³». Если всё чисто — «Пересечений нет».
4. Можно сразу выбрать другой набор тел и проверить снова. **Esc** — закрыть; подсветка и карточка исчезают.

Касание гранью пересечением не считается (объёмы меньше 0,0001 мм³ отбрасываются).

### 6.3. Массовые свойства (масса, объём, центр масс)

**«Анализ ▾» → «Массовые свойства»** — масса детали из выбранного материала, объём, площадь поверхности, габариты, центр масс.

1. Выберите тела (или выделите заранее), Enter / ✓ ОК.
2. В углу окна — карточка «Массовые свойства»; центр масс отмечен оранжевой точкой с подписью **«ЦМ»**.
3. Поменяйте материал или плотность в панели — масса пересчитается сразу.
4. Можно выбрать другие тела; **Esc** — закрыть.

| Поле панели | Что значит |
|---|---|
| **Материал** | PLA (1,24 г/см³, по умолчанию), PETG (1,27), ABS (1,04), Алюминий (2,7), Сталь (7,85), Латунь (8,5) |
| **Плотность, г/см³** | Можно ввести свою; выбор материала подставляет его плотность |

Строки карточки:

| Строка | Единицы |
|---|---|
| Плотность, г/см³ | g/cm³ |
| **Масса** | g (граммы) |
| **Объем** | mm³ |
| **Область** (площадь поверхности) | mm² |
| **Габариты** | X × Y × Z, mm |
| **Центр масс** | координаты X, Y, Z |

Если выбрано несколько тел, сначала идёт **«Итого»** (массы и объёмы складываются, центр масс общий), затем строки по каждому телу. Для поверхности или кривой (нет объёма) масса 0 и центр масс «—». Масса для 3D-печати — без учёта заполнения: при 20 % заполнения реальная деталь легче.

![«Массовые свойства»: материал и плотность](images/07-mass-properties.png)

## 7. Аннотации: размеры и текст в 3D

Аннотации — **постоянные** размеры и пометки, которые сохраняются в документе. Все они складываются в папку **«Annotations»** в дереве (в режиме «По типам» — раздел «Аннотация» браузера).

Общее:

- После того как аннотация поставлена, команда сразу предлагает следующую — **Esc** заканчивает.
- Поле **«Text height»** (подпись английская) — высота текста в мм, по умолчанию 3,5. От неё же зависит размер стрелок.
- Аннотация, поставленная на геометрию тела, **привязывается** к ней: тело изменилось и перестроилось — размер переехал и показывает новое значение. Если привязанная геометрия пропала: «Ссылочная геометрия не найдена после перестроения (…); аннотация сохраняет последнее положение».

### 7.1. Размер (линейный размер между точками)

**«Прямое моделирование» → «Аннотация» → «Размер»** или **«Тело» → «Анализ ▾» → «Размер»**.

1. Первая точка («выберите точку начала, ESC для отмены») — привязывайтесь к вершинам, серединам, центрам.
2. Вторая точка.
3. Положение размерной линии и текста («выберите позицию размера, ESC для отмены»). Возле курсора — значение.

Размер показывает **прямое расстояние** между двумя точками (параллельный размер). Куда вы отводите курсор, в той плоскости и встаёт размер: если направление близко к оси X, Y или Z, появляется пунктир цвета оси (красный — X, зелёный — Y, синий — Z) — размер встаёт строго в эту плоскость.

### 7.2. Радиус и Диаметр

**«Аннотация ▾» → «Радиус»** / **«Диаметр»** (или «Тело» → «Анализ ▾»).

1. Щёлкните круглое ребро — окружность или дугу («Пожалуйста выберите круг или дугу»).
2. Положение текста — в плоскости окружности; направление от центра задаёт, куда идёт выносная линия.

Текст — `R12` или `Ø24`.

### 7.3. Угол (угловой размер между рёбрами)

**«Аннотация ▾» → «Угол»** (или «Тело» → «Анализ ▾» → второй «Угол»).

1. Первое прямое ребро («Пожалуйста выберите прямую конечность»).
2. Второе прямое ребро.
3. Положение дуги и текста. Увели курсор на другую сторону — получится дополнительный угол (больше 180°).

Если рёбра параллельны — «Две конечности параллельны — угол не измерить».

### 7.4. Текст (выноска, пометка)

**«Прямое моделирование» → «Аннотация» → «Текст»** или **«Тело» → «Анализ ▾» → «Текст»**.

1. Впишите текст в поле **«Текст»** панели (по умолчанию «Text»).
2. Щёлкните точку, на которую указывает выноска («выберите точку, на которую указывает выноска, ESC для отмены»).
3. Щёлкните, где стоит текст («выберите положение текста, ESC для отмены»).

Текст всегда повёрнут к экрану, с какой стороны ни смотреть. (Объёмные буквы-тело делаются командой [«Text» на странице 06](06-direct-modeling.md#414-text-объёмный-текст).)



### 7.5. Как изменить, передвинуть и удалить аннотацию

- **Выделить** — щелчок по тексту аннотации в окне или по строке в папке «Annotations».
- **Свойства** (панель «СВОЙСТВА»):
  - **«Имя»**;
  - у размера — **«Text height»** и **«Text override»** — текст вместо числа. Знак `<>` в нём заменяется измеренным значением: `<> H7` → «10 H7», `4 отв. Ø<>` → «4 отв. Ø6». Пустое поле — обычное значение с R / Ø / °;
  - у текста — **«Текст»** и **«Text height»**.
- **Передвинуть размер мышью** — потяните за текст: двигается текст и размерная линия, привязка сохраняется. Потяните за **конец** размера (в пределах ~12 пикселей от точки) — конец переедет в новую точку (с привязкой к вершинам), и именно этот конец отвяжется от геометрии. У углового размера можно тянуть и вершину.
- **Передвинуть текстовую выноску** — командой «Переместить» ([раздел 2.1](#21-переместить-move-сдвинуть)).
- **Удалить** — выделите и нажмите **Delete** (или «Изменить ▾» → «Удалить узел»). Удалить все — удалите папку «Annotations».
- Всё отменяется **Ctrl+Z**.

Тело, к которому привязан размер, нельзя положить в «Группу» (компонент) — программа оставит его отдельно с сообщением «Узел, измеряемый аннотацией, нельзя группировать — аннотация потеряет ссылку (узел остаётся независимым)».

## 8. Единицы и точность

- Все длины в Kern3D — **миллиметры** (в браузере — «Единицы: мм»), углы — **градусы**. Другие единицы не переключаются.
- **Аннотации**: длины, радиусы, диаметры — до 2 знаков после запятой, углы — до 1 знака; если дробная часть нулевая, она не пишется: `40`, `12.5`, `Ø24`, `R6.35`, `45°`.
- **Измерения** (Длина, Угол, Измерить выбранное) и **анализ** (массовые свойства, пересечения) — всегда 2 знака: `40.00`, `90.00°`; плотность — 3 знака.
- Дробная часть везде пишется **через точку**.
- Размер при наведении на ребро — по правилам аннотаций (`Ø10`, `R5 · 7.85`).

## 11. Проблемы и решения

| Что видите | Причина и что делать |
|---|---|
| «This node is input geometry and cannot be moved — edit it directly» | Выбран эскиз или опорная плоскость/ось/точка — их не перемещают, а редактируют (эскиз — двойной щелчок, плоскость — в её свойствах) |
| Повернул, а деталь повернулась не вокруг той оси | «Повернуть» крутит вокруг перпендикуляра к рабочей плоскости. Смените рабочую плоскость или используйте «Переместить/Копировать» с «Поворот X/Y/Z» |
| «Отразить» не сделал копию, деталь просто перевернулась | Включите «Клон» в панели |
| Массив по прямоугольнику дал 27 копий вместо 9 | По умолчанию «Число Z» = 3. Поставьте 1 |
| Не могу изменить одну копию массива | Массив собран в компонент («Группа» включена). «Разбить на части» или делайте массив с выключенной «Группа» |
| Круговой массив: копии легли на 2° друг от друга, а не по кругу | Угол — это шаг между соседями. Для равномерного круга: угол = 360 / Количество, или включите «Общая длина» |
| Метки «Длина» висят на экране | Это временные метки — × на каждой. После перезапуска документа их нет |
| Измерение показывает странное число | Привязка сработала не на ту точку. Смотрите на значок привязки у курсора; при необходимости выключите лишние привязки («Привязка ▲») |
| Анализ сечения остался после выхода из команды | Так задумано. Нажмите «Анализ сечения» ещё раз или кнопку «Сечение вкл/выкл» внизу |
| Пересечения тел: «Выберите хотя бы два тела» | Выбрано одно тело. Выберите все тела сборки рамкой |
| Масса слишком большая | Проверьте материал и плотность (по умолчанию PLA). Для печати учтите процент заполнения |
| Размер не обновился после изменения детали | Размер был поставлен на свободные точки, а не на вершины тела, или его конец передвигали руками. Поставьте размер заново, привязавшись к вершинам |
| «Ссылочная геометрия не найдена после перестроения» | Ребро/вершину, на которую ставили размер, удалили или сильно изменили. Аннотация осталась на старом месте — удалите и поставьте заново |
| «Две конечности параллельны — угол не измерить» | Для угла выбраны параллельные рёбра. Выберите непараллельные |
| Тело с размером не кладётся в группу | Размеры держатся за тело. Удалите аннотации или не группируйте это тело |

Нашли ошибку — **«Сообщить о проблеме»** на стартовом экране, или пишите в [группу в Telegram](https://t.me/HPA_AirSoft_System_Development/71332).

## 1. Что такое Kern3D

Kern3D — бесплатная программа для конструирования (CAD) от Genesis Tactical, основанная на Chili3D (лицензия AGPL-3.0). Работает прямо в браузере и как отдельная программа для компьютера ([«Телефон и программа для ПК»](15-phone-and-desktop.md)).

Что в ней можно делать:

- **Конструирование** — эскизы с размерами и зависимостями, параметрические тела (выдавливание, вращение, отверстия, скругления…), прямое моделирование, сборки, измерения.
- **Чертежи** — листы с видами, размерами и экспортом.
- **Лазер** — гравировка на плоскости и на поворотной оси, управление лазерным станком.
- **Фрезеровка (тест)** — траектории ЧПУ и управление станком GRBL.
- **STL и сканы** — импорт, превращение STL в редактируемую модель, работа со сканами ([«STL и сканы → CAD»](stl-and-scans.md)).

Единицы длины — миллиметры.

## 2. Стартовый экран

Открывается при запуске программы, когда нет открытых документов, и по щелчку на логотип **Kern3D** в левом верхнем углу главного окна.

![Стартовый экран](images/01-home.png)

Слева:

- логотип и номер версии (например, `v0.9.3`);
- кнопки **«Новый документ»** и **«Открыть документ»**;
- кнопка **«Назад»** — только если какой-то документ уже открыт: возвращает в него;
- внизу — настройки (язык, тема, инструменты сканов, см. [2.7](#27-настройки-на-стартовом-экране)).

Справа:

- заголовок «Добро пожаловать в Kern3D», подзаголовок «Эскизы, 3D-модели, сборки и чертежи.» и строка о браузере ([2.4](#24-браузер-и-станки-по-usb));
- **«Недавние проекты»** и **«Что нового»**;
- строка ссылок: «Вопросы, тесты и новости — группа в Telegram · FAQ: где что находится · Справка · Сообщить о проблеме»;
- внизу — авторы и лицензия.

### 2.1. Новый документ и Открыть документ

- **«Новый документ»** — пустой документ, сразу открывается главное окно. То же — кнопка **«+»** справа от вкладок документов.
- **«Открыть документ»** (**Ctrl+O**) — открыть файл документа с компьютера.

Подробно про файлы, сохранение, импорт и экспорт — в [«Файлах и проектах»](02-files-and-projects.md).

### 2.2. Недавние проекты

Список документов, сохранённых в этом браузере (команда **«Сохранить документ»**, Ctrl+S): картинка-превью, имя, дата.

- **Щелчок по карточке** — открыть. Если документ уже открыт, программа просто переключится на него. Пока документ загружается, видно окно «Выполнение Открыть документ».
- **Крестик** на карточке — удалить. Программа спросит «Удалить <имя>?». После «ОК» документ стирается **из хранилища браузера** (не только из списка). Если у вас нет его копии в файле — он пропадёт насовсем.

Пока список пуст, написано: «Пока нет недавних документов. Создайте или откройте документ, чтобы начать.»

### 2.3. Что нового

Колонка **«Что нового»** — список изменений по версиям, новые сверху: номер версии, дата (или «готовится» для версии в работе) и группы «Добавлено», «Изменено», «Исправлено». Версия, которая у вас запущена, выделена.

### 2.4. Браузер и станки по USB

Под заголовком — серая плашка с тем, где запущен Kern3D: например, «Chrome 131 · Windows» или «Kern3D · Windows» (в программе для ПК).

- Зелёная надпись **«Станки по USB: доступны»** — браузер умеет подключать станки (Chrome, Edge, Opera на компьютере) или это программа Kern3D.
- Если браузер не умеет: «В этом браузере станки по USB не подключаются. Откройте Kern3D в Chrome или Edge или в программе Kern3D.»
- На телефоне и планшете: «На телефоне можно смотреть модели и проекты. Станки подключайте с компьютера: Chrome, Edge или программа Kern3D.»

Совет убирается кнопкой **«Понятно»** — браузер это запоминает и больше его не показывает. Строка с названием браузера остаётся.

### 2.5. Ссылки: группа в Telegram, FAQ, Справка

Открываются в новой вкладке:

- **группа в Telegram** — вопросы, тестирование, новости версий;
- **FAQ: где что находится** — короткие ответы «где эта кнопка», страница FAQ в вики Kern3D на GitHub (https://github.com/GenesisHPA/kern3d/wiki/FAQ);
- **Справка** — вики Kern3D на GitHub (https://github.com/GenesisHPA/kern3d/wiki).

### 2.6. Сообщить о проблеме (отправить ошибку разработчикам)

Ссылка **«Сообщить о проблеме»** (подсказка: «Откроет форму на GitHub: версия и последние ошибки уже подставлены, допишите, что случилось»).

Что происходит:

1. Открывается новая вкладка со страницей создания задачи (issue) в репозитории Kern3D на GitHub. Нужен аккаунт GitHub — без входа GitHub попросит войти.
2. Заголовок уже начинается с версии: `[0.9.3] ` — допишите коротко, что сломалось.
3. Текст заполнен заготовкой:
   - **Что случилось / What happened:** — опишите своими словами;
   - **Как повторить / Steps:** — шаги по порядку;
   - версия Kern3D и строка браузера/системы;
   - **Последние ошибки / Recent errors:** — до 15 последних ошибок программы за этот сеанс, с временем (или «—», если ошибок не было).
4. Проверьте текст и нажмите **«Create»** / **«Submit new issue»** на GitHub. Ничего не отправляется, пока вы сами не нажмёте эту кнопку.

Что важно знать:

- Ошибки собираются только в памяти и только с момента запуска страницы. Если вы перезагрузили страницу после сбоя, списка ошибок уже не будет — опишите, что делали.
- Очень длинный текст обрезается (около 6000 знаков) — у GitHub ограничение на длину ссылки.
- Ссылка на стартовом экране. Если открыт документ — щёлкните логотип Kern3D, чтобы попасть туда; документ останется открытым.
- Без GitHub можно написать в [группу в Telegram](https://t.me/HPA_AirSoft_System_Development/71332); полный журнал ошибок можно скопировать из окна «Журнал ошибок» ([9.3](#93-индикатор-ошибки-и-журнал-ошибок)).

### 2.7. Настройки на стартовом экране

Внизу левой панели: **«Язык»**, **«Тема»** и блок **«Инструменты сканов / сетки»**. Что делает каждая — в [«Настройках»](14-settings.md#2-стартовый-экран).

## 3. Главное окно

![Главное окно с открытым документом](images/01-main-window.png)

Сверху вниз:

### 3.1. Верхняя строка: логотип, Файл, быстрые кнопки, вкладки документов

- **Логотип Kern3D** — на стартовый экран (документы остаются открытыми).
- Оранжевая кнопка **«Файл ▾»** — список: «Новый документ», «Открыть документ», «Сохранить документ», «Сохранить в файл», затем «Импорт (STL, STEP…)» (подпись «STL, STEP, IGES, BREP — открыть модель из другой программы») и «Экспорт (STL, STEP…)» («STL для печати, STEP/IGES/BREP для CAD»). Подробно — в [02](02-files-and-projects.md).
- **Быстрые кнопки**: «Сохранить документ», «Сохранить в файл», «Отменить», «Повторить».
- **Вкладки документов** — по одной на каждый открытый документ, с крестиком для закрытия. Щелчок — перейти к документу.
- Открытые **листы чертежей** (и другие редакторы поверх модели) — тоже вкладками, после документов. Щелчок по вкладке документа возвращает к модели.
- **«+»** — новый документ.

### 3.2. Командная строка

- Слева — **переключатель рабочего пространства** (подсказка «Рабочее пространство»), показывает, например, «КОНСТРУИРОВАНИЕ ▾» ([раздел 4](#4-рабочие-пространства-и-вкладки)).
- Дальше — **вкладки** этого пространства: в Конструировании «Тело», «Прямое моделирование», «Утилиты»; пока редактируется эскиз — ещё вкладка «Эскиз» (выделена другим цветом).
- Под вкладками — **группы команд** активной вкладки ([раздел 5](#5-группы-команд-значки-и-список-)).

Название кнопки и её горячая клавиша показываются во всплывающей подсказке при наведении мыши, например «Окружность (c)».

### 3.3. Слева: Браузер и Свойства

- **«БРАУЗЕР»** — дерево документа: «Параметры документа», «Начало координат», «Тела», «Эскизы», «Построения», «Чертежи» и т. д. Два режима: «По типам» и «Дерево документа».
- **«СВОЙСТВА»** — свойства выбранного объекта.

Ширину левой панели можно менять, потянув её правый край; границу между «Браузером» и «Свойствами» — потянув разделитель. Подробно — в [«Виде и выборе»](03-view-and-selection.md).

### 3.4. Внизу: история и строка состояния

- **Шкала истории** — операции документа по порядку. Пустая: «История пуста: создайте эскиз или тело». Двойной щелчок по операции — редактировать её; меню операции — «Редактировать», «Откатить сюда», «Подавить» / «Включить»; кнопки «В начало», «Шаг назад», «Шаг вперёд», «В конец». Подробно — в [«Теле (параметрическое моделирование)»](05-body-parametric.md).
- **Строка состояния**:
  - слева — подсказка, что сейчас делать. Без команды: «Зажмите колесо — сдвиг вида, Shift + колесо — поворот, прокрутка колеса — масштаб» (так при навигации по умолчанию; в других профилях навигации кнопки в подсказке другие, например «Ctrl + колесо»);
  - справа — **«Привязка»** с кнопкой ▲ и **«Отслеживание»** ([«Настройки»](14-settings.md#4-привязка-и-отслеживание), подробно — [03](03-view-and-selection.md));
  - **«Ошибки: N»** ([9.3](#93-индикатор-ошибки-и-журнал-ошибок)).

### 3.5. Панель вида и куб вида

Внизу по центру окна модели — панель вида: орбита, панорама, масштаб, «Вписать», режим отображения, перспектива/ортогональ, сетка, «Сечение вкл/выкл». Справа вверху — куб вида. Всё это — в [«Виде и выборе»](03-view-and-selection.md).

### 3.6. На телефоне

На узком экране «Браузер» и «Свойства» спрятаны: круглая кнопка **☰** (появляется, когда открыт документ) выдвигает их поверх модели, **✕** убирает. Лента прокручивается пальцем. Подробно — в [15](15-phone-and-desktop.md).

## 5. Группы команд: значки и список ▾

### 5.1. Как устроена группа

Каждая группа — это ряд значков и под ним **название группы со стрелкой ▾** (например, «Изменить ▾»).

- **Значки** — главные команды группы (не больше 8). Щелчок — запустить.
- **Название ▾** (подсказка «Все команды группы») — открывает список **всех** команд группы: значок, название, горячая клавиша. Здесь же команды, которых нет среди значков (на ленте они собраны «столбиками» и «наборами»).
- Особая группа «Завершить эскиз» на вкладке «Эскиз» — одна большая кнопка без списка.

Если команды нет среди значков — ищите её в списке ▾ своей группы или через [поиск команд](#6-поиск-команд-клавиша-s).

![Список «Изменить ▾» на вкладке «Тело»](images/01-group-dropdown.png)

### 5.2. Настроить значки группы

Значки группы можно расставить по-своему:

- **Поменять порядок** — перетащите значок мышью влево или вправо внутри своей группы.
- **Добавить команду на панель** — в списке ▾ нажмите **булавку** справа от команды («Показать на панели») или перетащите строку списка на значки группы. Значок встанет в конец (или туда, куда отпустили).
- **Убрать значок** — в списке ▾ нажмите закреплённую булавку («Убрать с панели»).
- **Вернуть как было** — в списке ▾ внизу **«Сбросить расположение значков»** (пункт есть, только если вы что-то меняли).

Ограничения:

- Перетаскивать можно только внутри одной группы — в другую группу команда не переносится.
- Расположение запоминается в этом браузере отдельно для каждой вкладки и группы. На другом компьютере или в другом браузере — своё.

## 6. Поиск команд (клавиша S)

Самый быстрый способ найти любую команду по названию.

1. Наведите мышь на окно и нажмите **S** (без Ctrl/Alt, не в поле ввода).
2. У указателя появится окно с полем «Поиск команд…».
3. Начните вводить название: «скругл», «отверст», «экспорт». Сначала идут команды, название которых начинается с введённого, потом — где с него начинается любое слово, потом остальные совпадения.
4. **↑ / ↓** — выбрать строку, **Enter** — выполнить, **Esc** — закрыть (внизу подсказка «Enter — выполнить, Esc — закрыть»). Можно просто щёлкнуть по строке.

В строке: значок, название, метка, откуда команда («Эскиз», «Тело», «Прямое моделирование», «Чертёж» — одно и то же «Скругление» есть и в эскизе, и в теле, и в прямом моделировании), горячая клавиша.

**Избранное.** При пустом поле сверху показан раздел «Избранное» — по умолчанию «Новый эскиз», «Выдавливание», «Скругление», «Переместить/Копировать», «Длина». Булавка в строке — «Закрепить сверху» / «Открепить». Избранное запоминается в этом браузере.

Если ничего не нашлось — «Нет подходящих команд». Выключенные в настройках инструменты (например, «Скан») в поиске не показываются.

## 7. Меню правой кнопки

**Щелчок правой кнопкой по окну модели** (без перетаскивания и когда никакая команда не выполняется) открывает круговое меню.

- **Восемь команд по кругу.** В конструировании: «Повторить: <последняя команда>» (или «Повторить команду»), «Новый эскиз», «Выдавливание», «Скругление», «Удалить узел», «Переместить/Копировать», «Отменить», «Вдавить/вытянуть». Пока открыт эскиз: «Завершить эскиз», «Линия», «Окружность», «Прямоугольник», «Обрезать», «Размер», «Отменить», «Повторить».
- Ведите мышь в сторону команды — она подсветится; щелчок выполняет. **Esc** или щелчок в центр — закрыть.
- **Список под кругом** — команды для объекта под указателем (он сразу выделяется):
  - тело: «Скругление», «Фаска», «Оболочка», «Переместить/Копировать», «Выровнять», «Внешний вид», «Массовые свойства», «Удалить узел»;
  - эскиз: «Редактировать эскиз», «Выдавливание», «Вращение», «Удалить узел»;
  - построение (плоскость, ось): «Новый эскиз», «Удалить узел»;
  - пустое место: «Новый эскиз», «Импорт (STL, STEP…)», «Анализ сечения», «Повторить».

Правый щелчок по строке в **«Браузере»** открывает тот же список для этого объекта плюс «Скрыть» / «Показать».

Пока работает команда, правая кнопка принадлежит ей, и меню не открывается.

## 8. Панель команды: параметры, ОК и Отмена

Когда команда запущена, у правого края окна модели появляется её **панель**: значок и название команды, поля параметров, кнопки.

- **Поля**: числа, списки, флажки, кнопки — у каждой команды свои, описаны на её странице. В числовом поле можно написать выражение или имя параметра документа (например, `width / 2`); **Enter** — применить. Если выражение не подходит, появится сообщение об ошибке и в поле вернётся прежнее значение.
- Пока команда ждёт выбора, внизу: **«Выбрано N»**, **«ОК»** (принять выбор) и **«Отмена»**.
- Панель можно **перетащить** за строку с названием («Потяните, чтобы переместить окно»). Следующие панели откроются там же — до перезагрузки страницы.
- **Esc** отменяет команду (или текущий шаг).

**Ввод числа с клавиатуры.** Когда команда ждёт точку или расстояние в окне модели (линия, перемещение, выдавливание…), начните печатать цифру или минус — у указателя появится поле. **Enter** — принять, **Esc** — отказаться. Ошибочный ввод подсвечивается подсказкой под полем.

**Редактирование операции.** Двойной щелчок по операции в истории (или в дереве) открывает такую же панель с её параметрами. Изменения применяются сразу (модель перестраивается на глазах); **«ОК»** оставляет их, **«Отмена»** и **Esc** откатывают всё, что поменяли в этой панели.

![Панель команды (здесь — «Параллелепипед»)](images/01-command-panel.png)

## 9. Сообщения, окно прогресса и «Ошибки»

### 9.1. Всплывающие сообщения

Короткие сообщения появляются поверх окна на 2 секунды: «Документ сохранен», «Удалено N объектов», «Инструмент выключен в настройках» и т. д. Ошибки — красным. Новое сообщение заменяет предыдущее.

Частые:

| Сообщение | Что значит |
|---|---|
| «Команда <имя> выполняется» | Эта же команда уже запущена, или работает команда, которую нельзя прервать. Закончите или отмените её (Esc) |
| «Инструмент выключен в настройках» | Инструмент «Скан» выключен на стартовом экране ([14](14-settings.md#23-инструменты-сканов--сетки)) |
| «Сбой ядра геометрии: его память может быть повреждена. Сохраните работу и перезапустите приложение.» | Внутренний сбой расчёта формы. Сохраните документ в файл и перезагрузите страницу |

### 9.2. Окно прогресса

Долгие операции (перестройка STL, подготовка скана, большие импорты) показывают окно: название, текущий этап, полоса с процентами, прошедшее время (м:сс) и кнопка **«Отмена»**.

- **«Отмена»** или **Esc** — остановить. Кнопка меняется на «Останавливаю…», затем сообщение «Остановлено — ничего не изменено».
- В программе для ПК тот же прогресс виден на значке в панели задач.

Короткие действия (открытие документа, сохранение) показывают окно с крутящимся значком: «Выполнение Открыть документ» и т. п.

### 9.3. Индикатор «Ошибки» и «Журнал ошибок»

Справа в строке состояния — **«Ошибки: N»** (подсказка «Просмотр ошибок»): сколько ошибок программы было с начала сеанса.

Щелчок открывает окно **«Журнал ошибок»**: последние 100 ошибок, новые сверху, с датой и временем и техническими подробностями. Кнопки:

- **«Подтвердить»** — закрыть;
- **«Очистить ошибки»** — очистить журнал и счётчик;
- **«Отмена»** — закрыть.

Журнал пригодится для сообщения об ошибке: скопируйте текст и приложите к [«Сообщить о проблеме»](#26-сообщить-о-проблеме-отправить-ошибку-разработчикам) или в Telegram. После перезагрузки страницы журнал пуст.

## 10. Отменить и Повторить (undo, redo)

- **«Отменить»** — **Ctrl+Z**, кнопка со стрелкой влево в верхней строке, или «Отменить» в круговом меню.
- **«Повторить»** (вернуть отменённое) — **Ctrl+Y** или **Ctrl+Shift+Z**, кнопка со стрелкой вправо.

Как работает:

- У каждого документа своя история отмены, до **50 шагов**. Более старые шаги забываются.
- Если после отмены сделать новое действие, отменённые шаги «вперёд» пропадают.
- История отмены живёт, пока документ открыт; после закрытия и повторного открытия отменять нечего.
- В поле ввода Ctrl+Z отменяет набранный текст, а не действие в модели.
- В редакторах чертежа и лазера — свои Ctrl+Z / Ctrl+Y (см. [раздел 13](#13-горячие-клавиши)).

Не путайте с **«Повторить последнюю команду»** (Пробел или Enter) — она запускает последнюю команду ещё раз.

## 11. Вкладка «Утилиты»: Тест производительности

**«Конструирование» → «Утилиты» → «Остальное» → «Тест производительности».**

Служебная проверка скорости для разработчиков и тестировщиков, для работы она не нужна:

1. Создаётся новый документ «Тест производительности».
2. В нём строится 8000 параллелепипедов случайного размера (сетка 20 × 20 × 20).
3. Окно браузера сообщает: «Создано фигур: 8000, время: N мс» — сколько миллисекунд ушло.

На слабом компьютере или телефоне это может занять заметное время и много памяти. Документ с тестом просто закройте без сохранения.

## 12. AI-ассистент

Чат, в котором можно описать деталь словами, а ассистент построит или изменит её в открытом документе. Работает через внешний сервис нейросети по вашему ключу API. Экспериментальная функция.

### 12.1. Как открыть

- **«Прямое моделирование» → «Остальное» → «AI-помощник»**, или
- **«Тело» → «Вставка ▾» → «AI-помощник»** (в списке группы), или
- поиск команд (S) → «AI-помощник».

Горячей клавиши нет. Нажатие той же кнопки ещё раз закрывает чат.

Чат открывается панелью у правого края окна. Ширину меняют, потянув левый край. **Потяните за заголовок** — чат станет отдельным плавающим окном; кнопка со стрелками в его заголовке возвращает его на место.

### 12.2. Что нужно: ключ API

При первом открытии появляется окно **«Настройки AI-помощника»**:

| Поле | Что это |
|---|---|
| **Провайдер** | Сервис: «Anthropic API», «Completions API» (OpenAI и совместимые), «Responses API» (OpenAI), «Google Gemini (free tier)», «OpenRouter (free models)», «Groq (free tier)» |
| **Адрес API (Base URL)** | Адрес сервиса — подставляется сам; меняйте, только если работаете через свой прокси или совместимый сервис |
| **Модель** | Имя модели — подставляется по умолчанию для выбранного сервиса, можно вписать другое |
| **Глубина размышления** | Сколько модели «думать»: «По умолчанию» (как решит сервис), low, medium, high, xhigh, max. Если ответ обрывается на рассуждениях — уменьшите |
| **Окно контекста (токенов)** | Сколько текста помещается в модель: 200K … 1M. Нужно только для индикатора заполнения |
| **Ключ API** | Ваш ключ. Под полем — где его получить и ссылка (на русском) |

**«Сохранить»** — сохранить, **«Отмена»** — закрыть без сохранения. Позже настройки открываются значком шестерёнки в заголовке чата.

Где получить ключ (подсказки под полем):

- Anthropic, OpenAI — платные: нужен баланс в кабинете сервиса (подписка Claude.ai или ChatGPT сюда не входит).
- Google Gemini, OpenRouter (модели с пометкой `:free`), Groq — есть бесплатный уровень с лимитами запросов.

**Ключ не хранится в Kern3D.** Он живёт только до закрытия страницы; браузер может предложить сохранить его как пароль — тогда он подставится сам. Остальные настройки (сервис, модель…) запоминаются в браузере. Нужен интернет.

### 12.3. Что умеет

- Строить тела по описанию: «создай брусок 10×20×5 и скругли рёбра 2 мм». Строит теми же параметрическими операциями, что и вы, — результат можно править вручную.
- Изменять существующее: выделенные объекты, параметры документа, материалы и внешний вид.
- Смотреть на модель (делает снимки вида), чтобы проверить свою работу; задавать уточняющие вопросы — на них отвечают в карточке прямо в чате.
- Принимать картинки: кнопка **«+»** слева в поле ввода или вставка из буфера (Ctrl+V) — например, эскиз или фото детали.
- Новый документ, экспорт выбранного.

Управление:

- **Enter** — отправить, **Shift+Enter** — новая строка. Во время ответа кнопка отправки становится «стоп».
- У каждого вашего сообщения есть кнопка возврата: вернуть документ и переписку к состоянию до этого сообщения (текст вернётся в поле ввода). У ответа — «Копировать».
- Значок часов — список прошлых разговоров («Беседы»), **«+»** — новый разговор («Новая беседа»). Разговоры хранятся в документе.
- Индикатор у кнопки отправки показывает, насколько заполнен контекст модели.

### 12.4. Ограничения

- Нужен открытый документ («Нет открытого документа — сначала создайте или откройте его»).
- На одно сообщение — до 100 шагов работы. Если не хватило: «Достигнут лимит шагов для этого сообщения — напишите «продолжай»…» — напишите «продолжай».
- Качество и скорость зависят от модели и сервиса; бесплатные модели ошибаются чаще и упираются в лимиты.
- Ассистент может ошибиться. Проверяйте размеры; лишнее отменяйте кнопкой возврата или Ctrl+Z.
- В строке состояния может появиться надпись «AI bridge» — это служебное подключение для разработчиков (страница открыта с параметром `?bridge=`); обычному пользователю она не нужна.

| Delete | Удалить выделенное (в режиме «Узлы» — узел; там же Backspace) | Редактор лазера |
| Стрелки | Сдвинуть выделенное на 1 мм | Редактор лазера |
| Shift+стрелки | Сдвинуть на 10 мм | Редактор лазера |
| ↑ / ↓ в числовом поле | Число на шаг больше / меньше (Shift — на 10 шагов); колесо мыши — так же | Поля панелей лазера |

Подробно — в [10](10-laser.md) и [11](11-laser-rotary.md).

### 13.6. Фрезеровка: ручное перемещение станка

| Клавиши | Действие | Где работает |
|---|---|---|
| ← / → | Ось X − / + | Панель станка фрезеровки, станок подключён |
| ↑ / ↓ | Ось Y + / − | То же |
| Page Up / Page Down | Ось Z + / − | То же |
| Esc | Остановить всё движение | То же |

При шаге «Непрерывно» станок едет, пока клавиша нажата; при заданном шаге — один шаг на нажатие. Подробно — в [13](13-machine-station.md).

### 13.7. Окна и поля

| Клавиши | Действие | Где работает |
|---|---|---|
| Enter | Нажать кнопку подтверждения | Диалоговые окна |
| Esc | Отмена / закрыть | Диалоги, окно прогресса, списки ▾, меню, панель операции |
| Enter | Применить значение | Числовые поля панели команды и свойств |
| Enter / Shift+Enter | Отправить / новая строка | Поле ввода AI-ассистента |

## 14. Проблемы и решения

| Что видите | Причина и что делать |
|---|---|
| Нужной кнопки нет на ленте | Она в списке ▾ своей группы или убрана вами со значков. Найдите через поиск (S) или «Сбросить расположение значков» в списке группы |
| Кнопок группы «Скан» нет | Выключены на стартовом экране ([«Настройки»](14-settings.md#23-инструменты-сканов--сетки)) |
| Буквенные клавиши не работают | Включена русская раскладка, курсор в поле ввода, или фокус в другом окне (лазер, чертёж). Переключите раскладку, щёлкните по окну модели |
| «Команда … выполняется», новая команда не запускается | Закончите или отмените текущую (Esc, «Отмена» в панели) |
| Правая кнопка не открывает меню | Работает команда (правая кнопка у неё) или мышь сдвинулась при щелчке. Нажмите Esc и щёлкните, не двигая мышь |
| Пропал документ из «Недавних проектов» | Нажат крестик на карточке — документ удалён из браузера. Откройте копию из файла, если она есть |
| «Сообщить о проблеме» открыл пустой список ошибок | Ошибки собираются только с запуска страницы. Опишите, что делали, или приложите «Журнал ошибок» до перезагрузки |
| «Ошибки: N» растёт | Откройте журнал, скопируйте и пришлите разработчикам; «Очистить ошибки» обнуляет счётчик |
| Ctrl+Z ничего не отменяет | Отменять нечего (документ только что открыт, или прошло больше 50 шагов), или курсор в поле ввода |
| AI-ассистент просит настройки снова | Ключ не хранится — введите его или дайте браузеру сохранить как пароль |

Нашли ошибку — **«Сообщить о проблеме»** на стартовом экране, или пишите в [группу в Telegram](https://t.me/HPA_AirSoft_System_Development/71332).
